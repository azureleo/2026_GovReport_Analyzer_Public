## 1. 요약

같은 문서 안에서 **수송 부문 2033년 목표감축량이 두 값으로 표기**되어 있다. 표·그림·지분율·퍼센트 서술 등 5곳은 **3,285천 톤CO₂eq**로 정합하는데, 부문 서술 본문 한 곳(p191)만 **3,383천 톤CO₂eq**로 적혀 있다. 흥미로운 점은 **같은 페이지의 2030년 값은 모든 근거가 일치**한다는 것 — 즉 이 문서의 본문·표 대조가 항상 어긋나는 것이 아니라, 특정 값 하나만 고립적으로 어긋난다. 우리는 "표 우선" 같은 기계적 규칙이 아니라 **산술 검산 + 독립 근거 다수결**로 3,285를 정본으로 판정했고, 3,383이 실재하는 다른 통계 축일 가능성 2건을 검증해 모두 기각했다.

## 3. "3,383이 실재하는 다른 축의 값 아닌가" — 가설 2건 검증·기각

원문 내부 비일관으로 결론 내리기 전에, 3,383이 오기가 아니라 **다른 집계 방식의 실재값**일 가능성을 검증했다.

- **가설 ⓐ 수송 사업 카드 감축량의 합계다** → 기각. 추진과제 장의 수송 부문 사업 카드 헤드라인(2033년 값)을 전수 합산하면 약 2,500천 톤 수준으로 3,383과 불일치. (p254 전기차 425.5 / p258 2.9 / p261 336.4 / p263 1,231 / p264 75.4 / p270 8.5 / p272 185.2 / p281 238.4 + 2030년 전용 카드 p251 25.7·p267 5·p285 1.6·p287 13.5 등. 카드별 연간/누적 표기가 혼재해 합산 자체의 정밀도는 낮으나 3,383과의 간극을 메울 수 없음)
- **가설 ⓑ 인근의 다른 총괄값이다** → 기각. 근처에서 발견되는 유일한 유사 규모 값 p244의 "2033년까지 3,878천 톤"은 **건물 온실가스 총량제(B3-2) 사업**의 목표로, 수송 부문과 무관.

또한 PDF 전문 검색으로 3,383이 이 한 문장 외에 재등장하지 않음을 확인했다. **결론: 3,383은 어떤 통계 축으로도 재구성되지 않는 고립값 — 원문 작성 오류(개정 시 본문 미갱신 등)로 추정.**

## 4. 판정 원칙: "표 우선"이 아니라 "산술 검산 + 다수 근거 수렴"

이 사례에서 정본 판정의 근거는 표라는 **형식**이 아니라:

1. **산술 검산** — 감축량은 정의상 `배출전망 − 목표배출량`. 두 인벤토리 축의 표에서 독립적으로 같은 값(3,285)이 산출된다.
2. **독립 근거 다수결** — 서로 다른 페이지·형식(표 2곳, 본문 불릿, 지분율, 그래프, 퍼센트 서술)의 5개 근거가 수렴하고, 반대 근거는 1곳이며 그 1곳은 **자기 문장 안의 퍼센트와도 모순**된다.

같은 페이지·같은 문장 형식이라도 2030년 값은 전 근거가 일치했다는 점이 대조군 역할을 한다 — 문서의 본문이 체계적으로 신뢰 불가한 것이 아니라, 특정 값 하나가 고립적으로 어긋났고, 다수결·검산이 그것을 식별해 냈다.

- **B(luna) 백엔드는 이 함정을 통과했다.** B는 정본 표(p187·p188)를 축으로 추출해 3,285를 기록했고, 본문의 고립값 3,383을 채택하지 않았다. 표 기반 추출 전략이 본문 서술의 국소 오류에 강건함을 보여주는 실증 사례.
