# 16시트 관찰값 vs 시각 골든 직접 채점 (2026-07-12)

## 목적

시각 리콜 병목이 "명명(채점기 의미완화 +2뿐)"이 아니라 "격리(본 시트 미반영) + 커버리지"라는
진단을 확정/반박한다. 본 시트가 아닌 격리 관찰값(16_시각자료목록)까지 포함해
**"vision이 읽기는 했는가"** 를 잰다. 비용 0 (재추출 없음).

## 데이터 소스와 방법

- **소스 ② 채택**: `output/서울_v6.1_luna_머지on.xlsx`의 `16_시각자료목록` 2,063행 파싱.
  - 추출값요약이 `항목 연도 값 단위 | {fields JSON} | 차단사유` 형태, 시각자료ID(`V{페이지}-{순번}`)에
    페이지가 보존되어 손실이 미미함을 실물 확인 — ①(캐시 재실행+덤프)보다 싸고 ③(캐시 원문 파싱)보다
    파이프라인 실제 관찰값에 충실(image_agent 파싱을 통과한 값이 측정 대상).
- 골든: `data/golden/서울특별시_골든셋_v1_초벌.xlsx` 시각 유래(이미지표·그래프·이미지) 315행 중
  채점제외 제외 **308행** (02: 274, 03: 4, 05: 12, 06: 18).
- 매칭(계층 티어, 관찰값의 숫자 집합 대상, 상대오차 0.5% — 채점기 `_상대오차일치`와 동일):
  - **T1** 페이지(±1) + 연도 + 값
  - **T2** 연도 + 값 (페이지 무관)
  - **T2s** 연도 + 값×10^k (k=±1~3, 단위 스케일 차이 진단)
  - **T3** 값만 (연도 무시 — 우연 일치 상한 참고치)
- 스크립트: 스크래치패드 `score_obs_vs_visual_golden.py` (일회성 측정, 레포 조직 무변경)

## 결과

| 티어 | 행수 | 비고 |
|---|---|---|
| T1 페이지+연도+값 | **186** | 스팟체크 전건 동일 페이지·동일 캡션의 진짜 판독 |
| T2 연도+값 | 18 | 페이지 비앵커(우연 소량 가능) |
| T2s 스케일 허용 | 26 | ÷10·÷100·÷1000 등 — 읽었으나 단위 스케일 상이 |
| T3 값만 | 43 | 페이지 앵커는 2건뿐 → 41건은 우연 일치로 기각 |
| 미발견 | 35 | 전부 02_지역여건 |

**핵심: vision 판독 존재율 204/308 = 0.662 (연도+값 기준), 스케일 허용 + T3 앵커 포함 232/308 = 0.753.**
현행 채점기 시각 리콜 0.019(6/308)의 **34~39배**가 관찰값에 이미 존재한다.

시트별 판독 존재율(연도+값 기준): 02 0.635 · 03 0.500(4행 중 2) · **05 1.000(12/12 전부 T1)** · 06 0.889.

## 격리의 세부 원인 3가지 (매칭 204건의 차단·미반영 사유)

1. **라우팅 블랙홀 (102/204건, 50%)**: vision이 `target_sheet="summary"`로 분류한 기후·인구·공원 차트를
   `_infer_target_sheet`의 legacy map이 `vision_strategy`로 치환 → `_merge_image_results`가
   `vision_strategy`는 **무조건 skip**. 극한강수 17·강우전망 17·장래인구 13·공원 11건 등
   02_지역여건 재료가 병합 심사조차 못 받음 (`agents/image_agent.py:633`, `:763`).
2. **그래프 보수 규칙**: `chart_type ∈ {꺾은선,막대,영역,복합}` & not table-like → "그래프 추정 후보"로
   일괄 차단 (`image_agent.py:693`). estimated 플래그(축 추정 여부)와 무관하게 **라벨 인쇄값도 차단** —
   매칭 관찰값 차단 사유의 지배 항목.
3. **연도 범위**: `IMAGE_CHART_MERGE_YEARS = 2018~2050` — 02_지역여건의 본질인 과거 시계열
   (2005·2013 등)이 "연도 범위 외"로 원천 차단. "연도 없음/비숫자"(관찰값에 연도 미기록) 계열도 다수.

## 커버리지 잔여 (미발견 35 + T3 비앵커 41 = 76행, 24.7%)

- **요소 단위 완전 맹점은 2개뿐**: E028(p83 승용차 등록대수), E067(p129 에너지다소비건물 소비량).
  미발견 76행 전건이 "해당 페이지에 관찰값 존재" — 요소는 읽었으나 행이 빠진 **깊이(tail) 누락**.
- 집중 요소: E025 총 사업체 수(32행 중 24 누락), E068 에너지다소비건물 수(18 중 15),
  E023 장래인구추계(26 중 13 — 환각 위험 이력이 있는 그 차트, 과거 연도 행 위주 누락).
- T2s 26행은 단위 스케일 환산 문제(천 단위 등) — 판독은 됨, 병합 시 단위 정규화 사안.

## 판정과 분기 권고

**진단 확정: 병목은 명명이 아니라 격리.** 판독 존재율 0.66~0.75 vs 채점 리콜 0.019 —
격차의 지배 원인은 라우팅 skip(50%) + 그래프 일괄 차단 + 연도 범위이며,
커버리지는 부차(요소 맹점 2개, 나머지는 깊이 tail).

**권고 분기 = 게이트/병합 경로 완화 라운드** (판독 커버리지 라운드 아님). 지렛대 순서:

- **R1 라우팅 수정**: `summary→vision_strategy` 치환 제거 또는 vision_strategy 판정 전
  분류 필드·캡션 기반 재추론(기후/인구/공원/건축물 → regional_conditions). 단독으로 매칭 102건 직결.
- **R2 그래프 규칙 세분화**: 축 추정(estimated=true)만 차단하고, 라벨 인쇄값은 M2-4 게이트
  (G1 키 완성 + G5 교차검증) 경로로 병합 심사 허용. E023형 환각은 G5가 방어(설계 의도 그대로).
- **R3 연도 범위 완화**: 시트별 연도 범위 도입 — 02_지역여건은 과거 연도(1990~) 허용.
- 병합 후 채점 매칭은 기존 의미완화 티어 + 38쌍 명명 규약 재료가 담당(이미 준비됨).

### 한계·주의

- 존재 ≠ 병합 가능: 병합에는 키 완성(지표범주 등)이 필요한데 분류 필드 공급은 19/31 응답 —
  R1~R3 후에도 일부는 G1에서 정당 차단될 수 있음(그건 프롬프트/스키마 사안).
- T2 18건은 페이지 비앵커라 소량의 우연 포함 가능(핵심 결론에 영향 없는 규모).
- 서울 단일 문서 측정 — R1~R3 구현 시 관례대로 강원·경기 3중 게이트 확인 필요(지자체 불변 원칙).
