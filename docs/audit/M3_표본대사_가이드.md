# M3 L4 표본 대사 가이드 (2026-07-19)

무골든 추정 밴드("값일치율 ≥ 값합의율−4pp")를 사람 원문 대조로 검증하고,
저합의 시트의 책임 소재(A 오류 / B 오류 / 축 발산 / 원문 부재)를
확정하는 작업입니다. 지자체당 30행, 행당 1~3분, 지자체당 약 1시간
예상입니다.

## 파일

- `data/review/M3_표본대사/판정지_{서울,강원,경기}.md` — A값·B값·
  출처페이지가 사전 채움된 표. **표의 '판정'·'비고' 컬럼만 채우면
  됩니다.**
- A = flash-lite 산출물(v63f), B = luna 산출물(v73). 표본은 값합의율
  하위 3시트 × 10행(값불일치 우선)입니다.

## 절차 (행 단위)

1. 행의 **키**를 읽습니다. 예: `시나리오=bau|부문=가정|연도=2030` →
   "2030년 가정 부문 BAU 전망값"이라는 사실.
2. **출처페이지(pNN)** 로 원문 PDF를 엽니다. 페이지 번호는 PDF 뷰어의
   물리 페이지 순번입니다(문서 인쇄 페이지 아님). A·B의 페이지가
   다르면 둘 다 확인합니다.
3. 원문에서 그 사실의 실제 값을 찾아 **판정 코드**를 기입합니다:

| 코드 | 의미 |
|---|---|
| `A정답` | 원문값 = A값 (B는 오추출) |
| `B정답` | 원문값 = B값 (A는 오추출) |
| `둘다정답` | A·B가 **서로 다른 표**의 원문값을 각각 정확히 읽음 — 비고에 두 표 제목/축을 반드시 명시 |
| `축상이` | 같은 사실인데 단위·인벤토리 축 표기만 다름(예: 천톤 vs 톤의 1,000배 관계) |
| `둘다정답아님` | 원문값이 A·B 어느 쪽과도 다름 |
| `원문없음` | 그 키의 사실이 원문에 없음(환각·오배치 의심) |
| `판정불가` | 원문이 모호하거나 페이지를 특정 못 함 |

4. **비고**에 원문 실제 값·표 제목·페이지를 짧게 적습니다.

## 판정 요령과 함정

- **단위 함정**: A=천톤·B=톤이면 1,000배 차이가 같은 값일 수 있습니다
  → `축상이` + 비고에 단위.
- **같은 페이지의 복수 표**(가장 중요한 신호): 경기 p.99처럼 지역전체
  전망과 관리권한 전망이 한 페이지에 공존하면 A·B가 서로 다른 표를
  읽었을 수 있습니다 → `둘다정답` + 비고에 두 표를 명시해 주세요.
  이 판정이 "시트 키에 축 구분 필드가 없다"는 계약 문제(발주 문의
  3번과 동일 계열)의 실측 증거가 됩니다.
- **반올림**: 원문 반올림 표기(2.4→2)로 소수점만 다르면 값이 같은
  것으로 보고 비고에 "반올림"이라고 적어주세요.
- **단독 행**(구분=단독): 한쪽에만 있는 행 — 원문에 실제로 있으면
  그쪽 백엔드의 리콜 우위 증거(`A정답`/`B정답`), 없으면 `원문없음`.
- **우선순위**: 경기 05·09 → 강원 06·09 → 14(3지자체 공통) 순이
  진단 가치가 높습니다. 서울 판정지는 캘리브레이션 재검증용이라
  후순위여도 됩니다.
- 서울은 팀원의 PDF 역추적 마킹본(`data/review/마킹_서울특별시_*.pdf`)
  을 열면 추출 행이 하이라이트돼 있어 빠릅니다. 강원·경기는 수동
  페이지 탐색입니다.
