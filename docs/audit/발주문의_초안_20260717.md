# 발주처 확인 요청 — 추출 계약 판정 3건 (2026-07-17 초안)

가이드라인 기반 추출 파이프라인 운영 중 원문·가이드라인만으로 판정할 수
없어 발주처 확인이 필요한 항목 3건입니다. 각 항목은 회신 즉시 코드/골든
수정으로 반영 가능한 상태로 준비돼 있습니다.

## 1. 03_배출현황_지역 — 배출유형 코드가 불명확한 시각 판독 19행

- **배경**: 서울 계획서의 일부 배출현황 차트(E044·E045·E050 등)는 값은
  명확하나 그 값이 직접배출/간접배출/흡수원 중 어느 배출유형인지 차트·
  캡션에 명시되지 않습니다. 현재 이 19행은 배출유형을 비워 채점 보류
  상태로 격리해 두었습니다(임의 배정 금지 원칙).
- **질문**: 배출유형이 원문에 명시되지 않은 시각 자료의 값은
  (a) 직접배출로 간주 / (b) 해당 인벤토리 절의 지배 유형을 상속 /
  (c) 미분류로 별도 표기 — 어느 규칙을 적용할까요?
- **반영**: 규칙 회신 시 19행을 골든셋에 편입하고 파이프라인 기본 규칙을
  동일하게 맞춥니다.

## 2. 14_점검실적 — 달성여부 코드 매핑 규칙

- **배경**: 가이드라인 코드(달성/부분달성/미달성 등)와 달리 일부 원문은
  자유 서술("정상 추진", "지연" 등)만 씁니다. 현재 해당 3건은 정답 발명을
  피하기 위해 채점 제외 상태입니다.
- **질문**: 원문 자유 서술 → 달성여부 코드 매핑 표(예: "정상 추진"→달성?
  "지연"→부분달성?)를 확정해 주실 수 있습니까? 또는 원문 표현을 그대로
  두는 것을 선호하십니까?
- **반영**: 매핑 표 회신 시 골든 3건을 편입하고 organizer 정규화 사전에
  반영합니다.

## 3. 06_감축목표 — 같은 기준연도의 복수 인벤토리 축 구분

- **배경**: 서울 계획서는 지역전체 감축목표를 두 인벤토리 축으로
  병기합니다 — 서울시 인벤토리(2005년 49,445천톤 기준, 2030년 40% 감축
  =29,667천톤)와 연료공급량 기준(2005년 52,342천톤, 감축률 39.8%).
  가이드라인 §5.2의 06 컬럼에는 인벤토리 축 구분 필드가 없어, 두 축의
  총괄 값이 같은 키(총괄|지역전체|합계|2005|2030)로 병합·대사되는 것을
  구조적으로 막을 수 없습니다(03에는 `inventory_mapping` 유사 필드 존재).
- **질문**: (a) 06에 인벤토리 축 컬럼을 추가하는 계약 확장을 승인하실지
  / (b) 지자체 공식 목표 축 하나만 추출 대상으로 지정할지(그 경우 우선
  축 기준은?) 확인 부탁드립니다.
- **반영**: (a)면 시트 계약·골든·채점기 확장, (b)면 우선 축 규칙을
  추출 지침에 반영합니다.
- **(2026-07-19 추가) 05_배출전망도 동일한 문제가 실측됐습니다**:
  경기 계획서는 같은 페이지에 지역전체 전망(예: 2030년 24,129천톤
  계열)과 관리권한 전망(77,357천톤 계열)을 병기하는데 05 컬럼에도 축
  구분 필드가 없습니다. 3번 답변 시 05를 포함해 주시면 한 번에
  반영하겠습니다.
