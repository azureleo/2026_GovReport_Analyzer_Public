# M2-4+5 시각 판독값 본 시트 병합 + 텍스트-시각 교차검증 구현명세서

> 기준 문서: 로드맵 §M2-4·§M2-5. 대상 브랜치: `feat/v6-measurement-baseline`
> (v5.3 소수정 완료 후 착수 권장 — S1~S3 정규화가 병합 키 품질의 전제).
> 이 문서는 대화 맥락 없이 코드베이스만으로 구현 가능해야 한다. 모호하면 보수적 선택.

## 측정 근거 (전부 실측 — 로드맵 원칙 "측정 없이 완화 금지" 충족)

1. vision(gemini-2.5-pro) 요소 리콜 0.976, **원문 라벨·표 인쇄 요소의 값 정확도 98%**
   (111/113), 축 눈대중 추정 포함 전체 0.81 — `docs/benchmark/서울시각요소_VLM벤치마크_v1.md`,
   표본채점(15요소 267트리플, 2026-07-07).
2. 축 추정값은 파이프라인이 이미 `estimated`로 자체 표기함(기존 보수 설계 작동 확인).
3. **위험 패턴 실측**: 라벨이 있는데 모델이 사전지식 유사값을 대입하는 환각(E023 인구
   차트 — 오류 38건 중 28건). → 병합은 라벨 기반이라도 **텍스트 교차검증과 묶어야** 한다.

## 목표

로드맵 M2-4("정확도 임계 이상 유형부터 단계적 병합")와 M2-5("텍스트-시각 교차 대조")를
하나의 게이트로 구현한다: **"라벨 기반(비추정) + 신뢰도 조건 + 텍스트 교차검증"을
통과한 시각 판독 행만 본 시트에 병합**하고, 나머지는 현행대로 16 시트에 격리한다.
설계는 지자체 불변 — 조건이 문서 표기가 아니라 판독 메타데이터(estimated/confidence)와
스키마 키에만 의존한다.

## 절대 제약

1. **신설 동작은 opt-in**: `VISUAL_MERGE_LABELED_ENABLED`(기본 **False**) 신설.
   기본 실행의 출력은 바이트 수준 불변이어야 한다(기존 표-고신뢰 자동병합 경로도 불변).
   활성화 결정은 아래 3중 게이트 실측 후 사람이 별도 커밋으로 한다.
2. 기존 opt-in 기본값·라우팅·프롬프트 문면 불변. OrganizerAgent 무LLM. 시트 계약 불변
   (병합 행은 기존 컬럼만 사용, `데이터상태=visual_only`·`출처페이지`로 추적).
3. 조용한 병합 금지 — 병합/차단 각각의 근거를 `19_검증리포트`(또는 18 병합로그 형식
   재사용)에 행 단위로 남긴다.
4. 코드·주석·커밋 한국어, push 금지, 기존 테스트 + 신규 회귀, 커밋별 통과.

## 1. 병합 게이트 (플래그 활성 시에만)

이미지 파이프라인의 chart observations(반영여부=검토로 격리되던 것들) 중:

| 조건 | 판정 |
|---|---|
| G1. `estimated` 아님(원문 라벨/표 기반 판독) | 필수 |
| G2. confidence ≥ `IMAGE_CHART_MERGE_MIN_CONFIDENCE`(기존 설정 재사용, 기본 medium) | 필수 |
| G3. 대상 시트의 1차 키 필드가 전부 채워짐(부문·연도 등 — v5.3 정규화 후 기준) | 필수 |
| G4. 참고자료 판정 아님(기존 `_is_reference_chart` 재사용) | 필수 |
| G5. **교차검증(M2-5)**: 같은 키의 텍스트 유래 행이 본 시트에 이미 있으면 → 값 0.5% 이내 일치 시 **병합 생략**(중복 방지, "교차일치" 기록) / 불일치 시 **병합 금지 + 검증리포트 "경고: 텍스트-시각 값 불일치"**(값 양쪽 명기) | 분기 |
| G5b. 같은 키의 텍스트 행이 없으면(시각 전용 데이터) → **병합 실행**, `데이터상태=visual_only` | 분기 |

- 키 동등성은 organizer dedup 키 체계(공개 별칭) 재사용. 수치 비교 0.5%는
  `_values_conflict`와 동일 기준.
- G5의 "텍스트-시각 값 불일치" 경고는 플래그와 무관하게 **항상** 기록해도 좋다
  (기존 교차 검증 패스 확장 — 출력 행 변화 없이 리포트만 늘므로 계약 안전).
  구현 부담이 크면 플래그 내부로 한정하고 사유를 주석으로.

## 2. 구현 위치

- 병합 판정·실행: `agents/organizer_agent.py`의 chart observation 처리부(기존
  표-유형 자동병합 로직 인접)에 순수 함수로. LLM 호출 금지.
- 신뢰도·estimated 메타데이터는 image_agent가 이미 observation에 남긴다 — 없으면
  결측으로 보고 병합 불가(보수).
- 병합 기록: 검증리포트 `영역="시각병합"` 행(병합/생략/차단 + 근거). 18 시트 형식을
  재사용해도 좋으나 시트 생성 조건(hybrid 전용)을 건드리지 말 것.

## 3. 테스트

1. 플래그 기본 False에서 출력 불변(기존 픽스처 회귀).
2. 활성 시: G1~G4 각 조건 미충족 → 차단 + 기록. 충족 + 텍스트 부재 → 병합 +
   visual_only. 텍스트 일치 → 생략 + 교차일치 기록. 텍스트 불일치 → 차단 + 경고.
3. 병합 행이 시트 계약 컬럼만 사용하는지(스키마 검사).

## 4. 3중 게이트 (활성화 결정 근거 — 구현 인수 후 별도 실측)

플래그 켠 서울 재정제(재추출 불필요 — 캐시 재실행 또는 S7 오프라인 재정제 확장)로:
- 골든 채점에서 **시각 유래 리콜 상승**(현재 골든의 그래프 후보 행 4 + 추후 확장분)과
  **값일치율 무하락**을 확인.
- 강원·경기에서 병합/차단/경고 건수 분포가 상식적인지(병합 폭주 없음) 확인.
결과 표를 보고서로 남기고, 활성화(기본 True 전환)는 사람이 결정한다.

## 최종 인수 절차

1. `python -m pytest tests/ -q` 전부 통과, 커밋별 통과. 기본 실행 출력 불변 증명.
2. 활성 스모크: 서울 캐시 재실행(비용 ~0) 1회로 병합·차단·경고 각 1건 이상 실례를
   검증리포트에서 캡처해 보고에 포함.
3. 보호 불변 diff 0. push 금지.
