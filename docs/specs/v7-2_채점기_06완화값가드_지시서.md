## 2. 작업 항목

### G1 — 06 완화 후보 목표수준 값 검증

`_세부부문완화후보허용`과 같은 위치에 06 전용 허용 함수를 추가하고 완화
후보 선별(현행 라인 237 부근의 `_세부부문완화후보허용` 호출부)에 함께
적용한다:

- `sheet_name != "06_감축목표"` → 허용(True).
- 골든과 출력의 `목표수준`을 `dedup_key_text`로 정규화해 비교. **어느
  한쪽이 빈 값이거나 서로 같으면 허용**(현행 동작 보존 — V1과 동일 구조).
- 서로 다르면(발산) 값 검증: 수치 필드 `목표감축량, 목표배출량, 감축률,
  기준배출량, 배출전망` 중 **양쪽 모두 값이 존재하는 필드가 1개 이상
  있고, 그 전부가 상대오차 0.5% 이내로 일치**할 때만 허용. 공통 존재
  필드가 0개면 제외(검증 불가능한 발산 매칭 차단).
- 기존 `_상대오차일치`·`값있음` 재사용.

### G2 — 테스트

- 목표수준 발산+값 상이 → 완화 매칭 불형성(폐기물 338 vs 4906 케이스).
- 목표수준 발산+값 동일(표기 발산) → 완화 매칭 형성.
- 목표수준 동일(또는 한쪽 빈 값) → 현행 그대로 형성(값 무관).
- 공통 값 필드 0개 + 발산 → 불형성.
- 발산 + 일부 필드 일치·일부 상이 → 불형성(전부 일치 요구).
- 타 시트(03/04) 기존 가드 동작 불변 회귀 확인.
- 기존 317개 전부 커밋별 통과.
