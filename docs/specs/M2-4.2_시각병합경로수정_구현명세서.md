# M2-4.2 시각 병합 경로 수정(격리 해소) 구현명세서

> 대상 브랜치: `feat/v6-measurement-baseline` (HEAD 4a0d273 이후). 새 브랜치
> `feat/m2-4-2-merge-path` + **별도 worktree** 필수.
> 이 문서만으로 구현 가능해야 한다. 모호하면 보수적 선택.
> 플러그인 lint·리팩터 권고가 이 명세의 요구를 삭제/축소하게 두지 말 것.

## 측정 근거 (전부 실측 — `docs/audit/16시트관찰값_시각골든_직접채점_20260712.md`)

서울 v6.1 luna 머지on 기준, 시각 골든 308행 중 **204행(0.662)의 값이 이미
16_시각자료목록 관찰값에 존재**하는데 본 시트에 못 들어간다(채점 리콜 0.019).
매칭 204건이 병합 게이트에서 막힌 사유(19_검증리포트 차단 1,098건과 페이지 조인):

1. **G3 "대상 시트 미지원"이 최대 지렛대(~102건)**: vision이
   `target_sheet="summary"`로 답한 기후·인구·공원·건축물 차트(극한강수 17,
   강우전망 17, 장래인구 13, 공원 11 등)를 `_infer_target_sheet`의 legacy map
   (`agents/image_agent.py:633`)이 `vision_strategy`로 치환 →
   ① 자동병합 루프가 무조건 skip(`:763`) ② 라벨 병합 경로도 G3 미지원 차단
   (`vision_strategy`는 `_VISUAL_MERGE_KEY_FIELDS`에 없음). 이중 블랙홀.
2. **G1 판독필드 없음 + G3 1차 키 누락(~65건)**: vision 응답이 fields dict를
   아예 안 준 행(분류 필드 공급 19/31 응답) 또는 지표범주 등 1차 키 누락.
3. **G2 신뢰도 미달(~27건)**: `_chart_merge_decision`(`image_agent.py:700`)이
   "연도 범위 외"(IMAGE_CHART_MERGE_YEARS=2018~2050) 사유가 있으면 신뢰도를
   low로 강등 → 라벨 경로 G2에서 간접 차단. 02_지역여건의 본질인 과거 시계열
   (2005·2013 등)이 여기 걸린다.

라벨 병합 경로(G1~G5, `organizer_agent.py:1254`)에는 차트유형·연도범위 차단기가
없다 — "그래프 추정 후보"로 자동병합에서 막힌 라벨 인쇄값은 설계대로 라벨 경로가
받아 G5 교차검증으로 심사한다. 따라서 이번 라운드는 **게이트 판정 로직이 아니라
게이트에 도달하기 전의 경로(라우팅·신뢰도 강등·키 재료)** 를 고친다.

## 목표

격리 3원인을 해소해, `VISUAL_MERGE_LABELED_ENABLED=1` 실행에서 시각 골든
리콜이 실질 상승하고(합격 게이트 §5) 값일치율이 하락하지 않게 한다.
**vision 판독 능력을 올리는 라운드가 아니다** — 이미 읽힌 값을 버리지 않게
하는 라운드다. 깊이 tail(미판독 76행)은 범위 밖.

## 절대 제약

1. **지자체 불변**: 키워드·코드 매핑은 가이드라인(carbon_guideline.md) 표준
   어휘만. 특정 지자체·특정 문서의 고유 명칭/그림 번호를 코드·프롬프트에
   넣지 않는다.
2. **V2 지시 유지(키 기본값 금지)**: `지표범주="시각자료"` 같은 무근거 기본값
   주입 금지. S3의 키워드 매핑은 관찰값 자체 텍스트(캡션·항목·제목)에서
   결정론적으로 유도될 때만 채우고, 유도 불가면 **차단 유지**.
3. **G1~G5 판정 로직 자체는 불변** (G1 estimated 의미론, G5 교차검증 포함).
   허용 수정은 이 명세의 S1~S3가 명시한 지점뿐.
4. `VISUAL_MERGE_LABELED_ENABLED` **기본 False 불변** (기본 전환은 §5 실측 후
   사람 결정). estimated true-only 관례 불변. LLM_CACHE_DIR 관련 불변 —
   이번 라운드는 프롬프트를 건드리지 않으므로 **캐시 전량 히트(재추출 0, 비용 0)**
   여야 한다. 프롬프트·vision 스키마 수정 금지(그건 다음 라운드).
5. 코드·주석·커밋 한국어, push 금지, 커밋별 `python -m pytest tests/ -q` 통과.

## 구현

### S1 라우팅 블랙홀 제거 (`agents/image_agent.py` `_infer_target_sheet`)

1. `_LEGACY_MAP`에서 `"summary": "vision_strategy"` 항목을 제거한다.
   vision이 명시적으로 `vision_strategy`를 준 경우만 vision_strategy로 남는다.
2. 키워드 폴백(현행 `:646~658`)에 지역여건 계열을 **자동차/에너지 규칙보다
   뒤, ghg/전망 규칙들 앞**에 추가한다(순서 주의 — 기존 규칙의 판정 변화 금지):
   `["인구", "기온", "강수", "기후", "폭염", "한파", "공원", "녹지", "건축물",
   "사업체", "산업구조", "가구"]` 중 하나라도 있으면 `regional_conditions`.
   (가이드라인 §2 지역여건 지표 어휘 — 지자체 고유명 아님)
3. 기본 반환값(`emissions_regional`)은 불변.
4. 판정 근거를 남기기 위해, summary였다가 재추론된 관찰값은 `근거` 문자열
   끝에 `; 대상시트 재추론(summary)`를 덧붙인다(감사 가능성).

### S2 시트별 연도 정책 (`config.py` + `agents/image_agent.py`)

1. `config.py`에 추가:
   ```python
   # 지역여건·배출현황은 과거 시계열이 본질이라 병합 연도 하한을 넓힌다.
   IMAGE_CHART_MERGE_YEARS_BY_SHEET = {
       "regional_conditions": list(range(1990, 2051)),
       "emissions_regional": list(range(1990, 2051)),
   }
   ```
   (env 오버라이드는 불요 — 기존 관례상 리스트형 상수는 코드 상수로 둔다)
2. `_chart_merge_decision`의 연도 범위 검사(`:689`)를 대상 시트 기준으로:
   `allowed = config.IMAGE_CHART_MERGE_YEARS_BY_SHEET.get(target_sheet, config.IMAGE_CHART_MERGE_YEARS)`.
3. 신뢰도 강등 예외 목록(`:700`의 `["참고자료/해외사례", "연도 범위 외"]`)은
   **불변** — 연도 정책이 시트별로 옳아지면 강등도 자연히 옳아진다.
   (범위 외 연도는 여전히 low 강등 → G2 차단: 의도된 보수성)

### S3 지표범주 결정론 보강 (`agents/organizer_agent.py`)

대상: `regional_conditions` 후보에서 G3 "1차 키 누락(지표범주)"만 완화.

1. 헬퍼 `_infer_indicator_category(text: str) -> str | None`을 추가:
   캡션·항목·제목·지표명을 이어붙인 텍스트를 가이드라인 표준 4코드로
   결정론 매핑. 매핑표(가이드라인 §2 어휘만):
   - `에너지`: 에너지, 전력, 도시가스, 석유, 신재생, 연료
   - `자연환경`: 기온, 강수, 기후, 폭염, 한파, 공원, 녹지, 산림, 하천
   - `인문사회`: 인구, 가구, 세대, 주택, 건축물
   - `경제산업`: 사업체, 산업, GRDP, 종사자, 자동차, 차량, 수송, 교통
   복수 범주 키워드가 동시에 매칭되면 **None 반환(채우지 않음, 동률 비매칭
   원칙 — 채점기 의미완화와 동일 철학)**. 첫 매칭이 아니라 전 범주 검사 후
   유일할 때만 채택.
2. `_visual_candidate_row`의 `regional_conditions` 분기에서 지표범주가
   비었을 때만 `_infer_indicator_category`로 채운다. 다른 시트·다른 키 필드에는
   적용하지 않는다(배출유형·시나리오 등은 발명 위험 — 차단 유지가 정답).
3. 근거: 자동병합 경로는 이미 같은 추론을 한다(`image_agent.py:773`의
   키워드 분기). 라벨 경로만 이 추론이 없어 비대칭 차단이 생겼다.
   G5 교차검증·시각-시각 dedup(V3)은 그대로 적용된다.

### S4 테스트 (`tests/`)

기존 테스트 파일 관례를 따라 최소 다음을 추가(각 항목 독립 검증):

1. S1: `target_sheet="summary"` + 캡션 "장래인구추계" 관찰값이
   `regional_conditions`로 추론되고, 명시적 `vision_strategy`는 유지됨.
2. S2: `regional_conditions` 대상 2005년 표형 항목이 "연도 범위 외" 사유를
   받지 않고, `reduction_targets` 대상 2005년 항목은 여전히 받음.
3. S3: 지표범주 없는 후보가 캡션 "공원 종류별 공원수"로 `자연환경`을 얻어
   G3를 통과, "에너지 사용 사업체 현황"(에너지+경제산업 동시 매칭)은
   None → G3 차단 유지.
4. 회귀: `VISUAL_MERGE_LABELED_ENABLED` 기본 False에서 산출 불변
   (기존 재정제/채점 스냅샷 테스트가 커버하면 신규 불요 — 확인만).

## §5 실측 절차와 합격 게이트 (구현 인수 후 Claude 독립 재실행)

전부 캐시 재실행(비용 0). 프롬프트 불변이므로 캐시 미스가 나면 구현 오류다.

1. **flag-off 서울**: 텍스트 유래 리콜·값일치율 **바이트 수준 무하락**
   (S1·S2는 자동병합 경로에도 닿으므로 "표형·고신뢰" 신규 자동병합 행이
   생길 수 있음 — 생기면 행 수·내용을 보고하고 골든 지표 무하락 확인).
2. **flag-on 서울**: 채점기 실행 후,
   - 시각 유래 리콜(의미완화 포함) **0.0195 → ≥ 0.15** (그 미만이면 원인
     분석 보고 후 판정 보류 — 숫자 조작으로 맞추지 말 것),
   - 텍스트 유래 리콜·값일치율(텍스트 유래) 무하락,
   - 병합/생략/경고/차단 4경로 발화 수와 G코드 분포를 실측 전(병합 14·차단
     1,098)과 대비해 보고.
3. **강원·경기 flag-on**: 골든이 없으므로 분포 상식성 게이트 —
   병합 행 표본 20개 수동 열람(대량 오병합·연도 이상치·범주 오분류 없음),
   경고(텍스트-시각 불일치) 비율이 병합 대비 과반이면 불합격.
4. 산출물: `docs/audit/M2-4.2_병합경로_실측_20260712.md`(또는 실측일자)에
   위 세 게이트 수치 기록. 기본 True 전환 여부는 이 문서를 근거로 사용자 결정.
