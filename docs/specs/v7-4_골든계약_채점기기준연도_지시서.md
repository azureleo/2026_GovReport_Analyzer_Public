## 1. 작업 항목 (G1)

`scripts/golden_score_contract.py`의 일차키:

```python
"06_감축목표": ["목표수준", "목표범위", "부문", "목표연도"],
```
을 `["목표수준", "목표범위", "부문", "기준연도", "목표연도"]`로 확장한다
(organizer `_REDUCTION_TARGET_KEY_FIELDS` 순서와 정합: 기준연도가
목표연도 앞).

- **이차(완화)키는 불변**(`["부문", "목표연도"]`).
- **G2 — v7-2 값 가드의 기준연도 확장(2026-07-16 2차 정정 — 지시서
  귀책)**: 최초 지시는 "완화 티어+v7-2 값 가드가 담당"이라 썼으나,
  실제 가드(`_감축목표완화후보허용`)는 **목표수준 발산에만** 값 검증을
  적용한다(Opus 충돌 보고로 발견). 목표수준이 같고 기준연도만 다른
  쌍이 완화에서 무검증 재결합하면 D1의 취지가 무력화되므로 가드를
  확장한다: **목표수준 발산 또는 기준연도 발산(양쪽 채움·상이) 시
  공통 수치 필드 전부 0.5% 일치를 요구**(기존 조건·필드 목록 재사용).
  기준연도가 한쪽이라도 빈 값이거나 동일하면 현행 동작 유지.
- **빈 기준연도 규약(2026-07-16 정정 — 지시서 귀책)**: 최초 지시서는
  "빈 문자열 키 성분(빈 값끼리 일치)"으로 썼으나, 실제 `키()` 계약은
  **빈 성분이 하나라도 있으면 엄격 키 없음(None) → 완화 티어행**이며
  06의 목표수준·목표범위 빈 값 행에 이미 같은 규약이 적용되고 있다
  (Opus가 충돌 보고로 정확히 발견). 정정: **순수 필드 삽입만 하고 기존
  `키()` 규약을 그대로 따른다** — 빈 기준연도 행(어느 쪽이든)은 엄격
  제외, 완화 티어(부문+목표연도)+v7-2 값 가드가 담당. 특수 처리 금지
  조항은 이 의미로 유지된다.
- 리포트 형식·칼럼 불변.

## 2. 테스트 (2026-07-16 정정 반영)

- 기준연도 상이(2005 vs 2018) 동일 나머지 키 행이 엄격 비매칭 →
  완화 티어에서 값 상이면 차단(G2), 값 동일이면 허용.
- 목표수준 동일+기준연도 상이+값 상이 → 완화 차단(G2의 핵심 신규).
- 기준연도 빈 값 행(한쪽 또는 양쪽)은 엄격 키 없음 → 완화 티어행
  (기존 규약 일관성), 완화 가드는 기준연도 빈 값이면 기준연도 조건
  미발동.
- 기준연도 양쪽 채움·동일이면 엄격 매칭 정상, 완화 현행 동작 유지.
