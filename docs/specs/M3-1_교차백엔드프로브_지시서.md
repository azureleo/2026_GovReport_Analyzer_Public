## 2. 지표 정의

### L3 — 교차 백엔드 합의율 (핵심)

시트별(01~15, 채점기 `데이터시트` 계약 재사용)로:

- **키 매칭**: A행을 골든 자리, B행을 출력 자리로 두고 채점기
  `매칭하기`를 **보수 티어(엄격+완화)만으로** 호출한다. 무골든 신호는
  보수 티어만 쓴다(의미완화·문자유사 배제).
- **(2026-07-18 정정 — 지시서 귀책, Opus 충돌 보고 반영)**: 현행
  `매칭하기`에는 티어 선택 인자가 없어 "재사용+의미완화 배제"와
  "채점기 파일 불변"이 동시 성립 불가. **정정: `매칭하기`에 티어 선택
  인자 추가를 허용한다**(예: `보수티어만: bool = False` — 기본값에서
  현행 동작 바이트 불변, True면 의미완화·문자유사 티어를 건너뜀).
  로컬 재구현(대안 2)은 기각 — W3 캘리브레이션이 "프로브 합의율 ↔
  채점기 골든 정확도" 대응이므로 두 도구가 **같은 매칭 코드 경로**를
  써야 보정이 유효하다. 채점기 변경은 이 부가 인자 하나로 한정하고,
  기본 경로 바이트 불변을 신규 테스트로 고정할 것(기존 채점 결과
  회귀 테스트 포함).
- **키 합의율** = 매칭 수 / min(A 유효행, B 유효행). A·B 각각의
  단독 행 수·비율도 병기(리콜 격차 신호).
- **값 합의율** = 매칭 쌍 중 `값필드` 계약의 공통 존재 수치 필드가
  전부 상대오차 0.5% 이내인 쌍의 비율(수치 비교는 채점기
  `_상대오차일치` 계열 재사용, `텍스트값필드`는 정규화 문자열 비교).
  값필드 미정의 시트(서술형)는 키 합의율만.

### L1 — 자기 감사 밀도

A·B 각각의 19_검증리포트에서 심각도별(경고/정보)·유형별(충돌, 검산,
스케일, 원장, 빈 시트 — 항목 문자열 접두 기준) 건수를 집계하고 데이터
행 수로 나눈 밀도를 병기. 19 시트가 없으면 0 처리.

### L2 — 분포 상식성 (가이드라인 기준)

시트별로:

- 행수(A·B 각각).
- **일차키 필드 채움률**: 해당 시트 `일차키` 필드가 전부 채워진 행의
  비율(가이드라인 §5.2 컬럼 정의가 근거).
- **표준코드 매핑률**: 가이드라인 코드 체계 필드의 값이 표준 코드
  집합에 드는 비율 — 부문(§2.6.3 표준 부문: 건물/수송/농축산/폐기물/
  흡수원/전환/산업/수소/합계 계열), 목표수준(총괄/부문/세부부문/
  세부사업/연차경로), 달성여부·사업유형·전망방법(90_코드북 체계 —
  `utils/reference_data.py`의 코드북 정의 재사용), 데이터상태.
  해당 필드가 없는 시트는 생략.
- **연도 정합률**: 연도류 필드 값이 [문서메타 계획시작연도−15,
  계획종료연도+2] 밴드(기준연도 과거 표기 허용) 안인 비율. 문서메타
  부재 시 생략.

## 3. 리포트 형식

- md: 시트별 표(행수 A/B · 키 합의율 · 값 합의율 · A단독 · B단독 ·
  L1 밀도 · 채움률 · 코드 매핑률 · 연도 정합률) + "합의율 하위 시트"
  절(L4 표본 대사 후보 자동 지정: 값 합의율 하위 3개 시트, 시트당
  10행 표본 키 나열 — D2 규모 반영) + 산출물 경로·라벨 헤더.
- json: 같은 내용 구조화(후속 캘리브레이션 W3의 입력).
- 점수 게이트 아님 — 파일·형식 오류 시에만 비정상 종료(채점기 관례).
