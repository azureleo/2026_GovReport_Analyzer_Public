# M2-1 검증수정 지시서 — 독립 검증(2026-07-06)에서 확인된 결함 수정

> 대상: `scripts/audit_visual_inventory.py`, `tests/test_audit_visual_inventory.py` (커밋 4b701dd·417d480·6c1ff4c 위에 일반 커밋으로).
> 근거 명세: `docs/specs/M2-1_시각요소인벤토리감사_구현명세서.md`. 모든 결함은 독립 재실행으로 실측 확인됨.
> 절대 제약은 원 명세와 동일(파이프라인 무변경·LLM 0·의존성 0·한국어). **커밋 메시지도 한국어**(기존 3개 커밋의 영어 메시지는 건드리지 말 것 — 별도 결정).

## R1. 민감도 시뮬레이션 점수 오염 제거 — 중간 (핵심 산출물 신뢰성)

**증상**: `_triage_page_evidence`(:264)가 참고자료 이미지에 `score -= 20`을 적용한 값을
`scores[page]`·`top_score`에 저장한다. 참고자료 배제는 `IMAGE_TRIAGE_EXCLUDE_REFERENCE_CONTEXT`
라는 **별개 게이트**인데 이 오염이 `calculate_sensitivity`(:334-336)의
`IMAGE_TRIAGE_MIN_SCORE` 민감도 표까지 번져, MIN_SCORE를 3으로 낮춰도 참고 이미지가
절대 회복 불가한 것처럼 집계된다(서울 실측: E002 원점수 12 → 표시 −8). 임계 완화
의사결정의 근거 숫자가 저평가된다.

**수정**: 민감도·상세표에는 `_triage_image`의 **원점수**를 쓰고, 참고자료 여부는 별도
필드(`reference_filtered` 불리언 또는 사유 태그)로 전달한다. `참고자료_제외` 상태 판정
로직은 불변. `-20` 산술 삭제.

**수용**: 참고자료 이미지가 있는 페이지의 top_score가 원점수와 같음을 단위 테스트로 고정.
상세표에 참고자료 여부가 사유(`reference_context:*`)로 계속 표시됨.

## R2. dump 초안의 캡션 없는 벡터 페이지 누락 — 중간

**증상**: `dump_inventory`(:383)는 이미지 없는 페이지를 `caption_text`가 있을 때만 1행
남긴다. 이미지·캡션이 모두 없지만 `get_drawings()`가 많은 순수 벡터 차트 페이지는 초안에서
통째로 빠진다(합성 PDF 실측: 도형 40개 페이지가 초안 0행). G1/G3 감사 목적과 정면 상충.

**수정**: 이미지·캡션이 없어도 **drawing 수 ≥ 30**(민감도 표의 최저 시뮬레이션 기준과 동일)
이면 페이지 행을 초안에 추가한다(자동_벡터드로잉수 채움, 나머지 자동 컬럼 빈칸).

**수용**: 캡션 없음+도형 40개 합성 페이지가 초안에 나타나는 회귀 테스트.

## R3. `기록됨` 매칭 레코드 오매핑 — 중간

**증상**: `classify_inventory`(:313) `matched = page_records[:1]`이라 같은 페이지 두 번째
요소도 첫 레코드를 가리킨다(실측: E001·E002 모두 V10-001). 명세 §2.2-3은 "기록됨(복수면
전부 나열)"을 요구.

**수정**: expected 요소의 `matched_records = page_records`(해당 페이지 전부). 상태 판정
(`기록됨`/`동일페이지_부분기록`)은 불변.

**수용**: 요소 2·레코드 2 페이지에서 두 요소 모두 두 레코드를 나열하는 테스트.
