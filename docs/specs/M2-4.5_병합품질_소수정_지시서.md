## 배경

M2-4.4에서 라벨 시각 병합이 **기본 활성화**되어, 실측에서 확인된 배치 이슈가
이제 기본 산출물에 실린다. 전부 결정론 수정(비용 0)으로 닫는다. 근거 실측은
`docs/audit/M2-4.2_병합경로_실측_20260712.md`의 게이트3·M2-4.4 절.

## 절대 제약

1. G1~G5 판정 구조·estimated 관례·프롬프트 불변 — **캐시 전량 히트 인수 조건**.
   (S1~S4는 라벨 병합 경로와 관찰값 필드 구성만 손댄다)
2. 지자체 하드코딩 금지. 아래 허용된 어휘는 가이드라인·IPCC 표준뿐.
3. `dedup_key_text` 등 전역 정규화 함수 수정 금지(파급 과대).
4. 코드·주석 한국어, push 금지, 커밋별 `python -m pytest tests/ -q` 통과(현재 235).

## 수정 항목

### S1 전망성 관찰값의 03 유입 방지 (organizer_agent.py)

실측: 강원 03에 <표 2-52> "흡수원부문 온실가스 흡수 **전망**"의 2033·2040
행이 병합됨(값은 원문 그대로 정확 — 자리만 오류). 라벨 병합 경로에서
`sheet_key == "emissions_regional"` 후보에 한해:

- 관찰값의 제목(`제목`)에 "전망" 또는 "BAU"가 포함되면 대상시트를
  `emissions_forecast`로 재지정해 심사한다(시나리오 키가 없으면 G3가
  정당 차단 — 현황 시트 오염 방지가 목적이고 데이터는 16시트에 남는다).
- 재지정 시 차단/병합 사유 문구에 `대상시트 재지정(전망 키워드)`를 남긴다.
- `근거` 문자열은 검사하지 않는다(차단 사유·마커가 섞여 오탐).

### S2 % 비율값의 배출량 병합 차단 (organizer_agent.py)

실측: 강원 03에 '관리권한 외' 2018 **88.4 '%'** 가 배출량 필드로 병합됨.
라벨 병합 경로에서 `emissions_regional`·`emissions_management` 후보의
단위 문자열에 `%`가 포함되면 차단하고 사유 `G3 비교값 단위 부적합(%)`을
남긴다. 02_지역여건은 %가 정당한 지표(비중·비율)이므로 **건드리지 않는다**.

### S3 가스종의 부문 오배치 차단 (organizer_agent.py)

실측: 경기 03에 부문='이산화탄소/메탄/기타' 행 병합. 03 스키마(config
EXCEL_HEADERS)에는 가스종 필드가 없어 부문 배치는 스키마 오용이다.
라벨 병합 경로에서 `emissions_regional`·`emissions_management` 후보의
부문(관리부문) 값이 아래 IPCC 표준 가스명이면 차단, 사유
`G3 부문에 가스종(스키마 불일치)`:

`{이산화탄소, 메탄, 아산화질소, 수소불화탄소, 과불화탄소, 육불화황,
CO2, CH4, N2O, HFCs, PFCs, SF6}` (dedup_key_text 정규화 비교, 부분일치
아닌 전체일치만 — "기타"는 가스 문맥 특정이 불가하므로 목록에 넣지 않는다).

### S4 visual_only-텍스트 값동일 중복의 생략 전환 (organizer_agent.py)

실측: M2-4.4에서 세부범주 상이로 G5 텍스트 매칭을 이탈한 값 동일 중복이
최대 3행 유입(예: 최종에너지 합계 2021=13,405). `_apply_visual_labeled_merge`의
텍스트 교차 단계에 2단 매칭을 도입한다:

1. 현행 키(세부범주 포함)로 텍스트 행 탐색 — 기존 동작 그대로.
2. 1에서 **텍스트 행이 없을 때만**, `regional_conditions`에 한해 지표세부범주를
   제외한 키(지자체명+지표범주+지표명+연도)로 재탐색한다.
   - 값 일치(기존 `_values_conflict` 기준) → `생략`(사유에 `세부범주 완화 교차일치` 명시)
   - 값 불일치 → **병합 유지**(경고·차단 아님 — 세부범주가 다르면 다른 지표일
     개연성이 있어 보수적으로 기존 M2-4.4 동작을 보존한다. 단 사유 문구에
     `세부범주 상이 텍스트 값불일치 관찰`을 남겨 감사 가능하게 한다)
3. 시각-시각 dedup(V3)은 변경하지 않는다.

### S5 재추론 마커의 필드 분리 (image_agent.py + organizer_agent.py 소극 수정)

현행 `image_agent.py:730`이 `; 대상시트 재추론(summary)`를 근거 문자열에
덧붙여, 차단 사유 없는(반영) 관찰값에서 fields JSON 뒤에 붙으면
`_visual_fields`의 JSON 파싱을 깨뜨릴 수 있다(현 라벨 경로는 "검토"만
처리해 미발화 — 잠재 결함). 수정:

- 관찰값 dict에 별도 키 `"대상시트근거": "재추론(summary)"`를 넣고 근거
  문자열 부기는 제거한다.
- `_build_visual_inventory`의 추출값요약 조립에서 이 키가 있으면 말미에
  `| 대상시트 재추론(summary)`로 병기(16시트 감사 가시성 유지).
- `_visual_fields`는 수정하지 않는다(근거가 다시 순수해지므로).
