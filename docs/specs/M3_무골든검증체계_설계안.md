# M3 설계안 — 골든 없는 지자체의 품질 검증 체계 (2026-07-17, 사용자 검토용)

> 로드맵 M3("타지자체 일반화 — 비정형성 증명")의 국면 개시 설계안.
> 완료 기준(로드맵): 최소 2개 타지자체가 사람 개입 없이 완주(이미 달성
> — 강원·경기 luna 풀런 실패 0) + 문제 행 비율이 서울 수준 + **골든
> 없이도 품질을 추정·보증할 수 있는 체계**(본 설계의 핵심).

## 0. 문제 정의

현재 모든 정확도 수치는 서울 골든셋 하나에 기댄다. 강원·경기(그리고
미래의 임의 지자체)는 "완주했고 분포가 상식적"까지만 말할 수 있고
"얼마나 정확한가"는 말할 수 없다. 골든셋 제작은 지자체당 사람 작업
수일이 들어 일반화 경로가 아니다.

## 1. 설계 — 무골든 품질 신호 4계층

### L1. 결정론 자기 감사 (기존 인프라 지표화)

19_검증리포트의 이슈를 시트별 밀도로 정규화: 충돌률(중복 키 값 충돌/행),
검산 실패율(감축률·재정 합계), 스케일 혼재율, 원장 실패율, 빈 시트.
이미 생성되는 데이터라 비용 0 — 리포트 지표화만 필요.

### L2. 분포 상식성 (신규 결정론 스크립트)

시트별 행수 밴드, 필수 필드 채움률, 표준코드 매핑률(부문·달성여부·
전망방법·목표수준), 연도 범위 정합(문서메타 계획기간 대비), 출처페이지
분포. 지자체 불변 규칙만 사용.

### L3. 교차 백엔드 합의율 (핵심 신호, 비용 0)

**독립 백엔드 2개(gemini flash-lite vs codex luna)가 같은 키에서 같은
값(상대오차 0.5%)을 내면 그 행이 정답일 확률이 높다** — 서울 골든셋을
3소스 교차합의로 만들었던 원리의 2소스 상시화다. 산출물은 이미 3지자체
모두 양 축이 존재(v63f 기본·v73 luna)하고 캐시도 있어 **측정 비용 0**.

- 지표: 시트별 키 합의율(양쪽에 같은 키 존재), 값 합의율(합의 키 중
  값 일치), 단독 행 비율(한쪽에만 존재 — 리콜 격차 신호).
- 매칭은 채점기 엄격·완화 키 체계 재사용(골든 대신 상대 산출물을
  기준으로).

### L4. 원문 표본 대사 (사람/도구, 소량)

L3 신호가 약한 시트(합의율 낮음)에서 표본 N행을 출처페이지 역추적으로
원문 대조 — 팀원 PDF 역추적 검수도구 재사용 가능. 전수가 아니라 신호
검증용 표본.

## 2. 캘리브레이션 — 서울이 자(尺)가 된다

서울은 골든 실측(정확도)과 무골든 신호(L1~L3)를 **둘 다** 갖고 있다.

1. 서울에서 시트별 (L3 값 합의율, L1 이슈 밀도) → (골든 값일치율,
   리콜)의 대응표를 실측한다.
2. 예: "값 합의율 ≥0.9인 시트는 골든 값일치율 ≥0.9였다" 같은 보정
   관계가 성립하면, 강원·경기의 합의율로 **추정 정확도 밴드**를 제시
   할 수 있다.
3. 상관이 약한 시트는 그 사실 자체가 산출물 — L4 표본 검증 대상으로
   지정된다.

## 3. 과적합 교정 트랙 (로드맵 G4 승계)

L1~L3 진단에서 강원·경기가 서울 대비 열세인 지점이 나오면 서울 과적합
후보(라우팅 키워드, 기존계획 장 경계 패턴, 관리번호 정규화, 부문 표기)
를 교정하는 라운드를 연다 — 기존 관례(지자체 불변 수정+3중 게이트)
그대로.

## 4. 구현 계획 (승인 시)

- **W1**: `scripts/cross_backend_probe.py`(가칭) — 산출물 xlsx 2개를
  받아 L3 합의 리포트 생성(채점기 매칭 모듈 재사용, LLM 0).
- **W2**: L1·L2 지표화를 같은 리포트에 통합(무골든 품질 리포트 1장).
- **W3**: 서울 캘리브레이션 실측 → 시트별 보정표 문서화.
- **W4**: 강원·경기 적용 → 추정 밴드 산출 + L4 표본 목록 지정 →
  과적합 교정 라운드 여부 판정.
- 관례 유지: W1·W2는 지시서→Opus 구현→Claude 검증, W3·W4는 Claude
  실측. 파이프라인(agents/) 불변 — 전부 사후 진단 도구.

## 5. 결정 포인트 (사용자)

- **D1. 설계 승인**: L3 합의율 캘리브레이션 접근을 채택할지.
  (대안: 지자체별 미니 골든 제작 — 사람 비용 큼, 기각 권고)
- **D2. L4 표본 규모**: 지자체당 표본 행 수(권고: 신호 약한 시트당
  10행, 지자체당 ~30행).
- **D3. 미니 골든 여부**: 여력 시 강원 1개 수치 시트(예: 03)만 골든
  제작해 캘리브레이션을 타지자체에서 재검증(권고: W4 결과 본 뒤 결정).

## 6. 한계 (정직 기록)

- L3 합의는 "둘 다 같은 오류"를 못 잡는다(공통 원문 오독·공통 프롬프트
  편향). 서울 캘리브레이션이 이 잔차를 정량화하는 장치다.
- 서술형 시트(01/07/13)는 키 발산 탓에 합의율 자체가 낮게 나올 것 —
  v7-5 재진단(세분 수준 발산)과 같은 원인이며, 수치 시트 중심으로
  운용한다.
