## 설계 원칙: 발명이 아니라 가이드라인 준수

이 라운드는 새 명명 규약을 만드는 것이 아니다. `carbon_guideline.md`가 이미
02 시트의 컬럼 의미를 정의하고 있고(엑셀 작성의 최우선 기준), 현행 시각 병합
후보 조립이 그 정의를 위반하고 있어 바로잡는 것이다.

가이드라인 근거 (전부 원문 확인, 2026-07-12):

1. **§5.3 `02_regional_conditions` 컬럼 정의**:
   - `indicator_subcategory` 예시 = "기온·강수량 / 인구 / GRDP / 전력소비량 등"
     → **차트·표 수준의 중분류**가 들어갈 자리.
   - `indicator_name` 예시 = "연평균기온, 폭염일수, 인구수, 자동차등록대수"
     → **개별 시리즈 단위의 지표**가 들어갈 자리.
2. **§2.2 추출 원칙**: "연도별 데이터는 넓은 표 형태로 두지 말고 가능하면
   `연도-지표` 행 단위의 long format으로 저장한다" → 다시리즈 차트의 각
   시리즈(연령대, 연차구간, 연료 등)는 **각각 별개의 지표 행**이어야 한다.
3. 골든셋 구조도 동일(사람 확인 통과분): 지표세부범주='인구',
   지표명='장래인구추계 0~14세 인구' — 시리즈가 지표명에 들어간다.

## 현행 위반과 실측 피해 (M2-4.2 실측, `docs/audit/M2-4.2_병합경로_실측_20260712.md`)

vision 관찰값에는 두 정보가 다 살아있다 — `항목`에 시리즈 라벨("0-14세 인구",
"10년 미만"), fields `지표명`에 차트 수준 명칭("연령별 인구", "건축물 연차별
현황"). 그런데 `_visual_candidate_row`(`agents/organizer_agent.py:1124`)가
`지표명 = fields.지표명 우선, 항목은 폴백`으로 조립해 시리즈 라벨을 버린다:

- 같은 차트의 시리즈 6행이 병합 키(지표범주+지표명+연도)에서 **한 키로 붕괴**
  → 첫 행만 병합, 나머지는 V3 "동일 키 값 충돌" 경고로 탈락(서울 flag-on
  경고 36건 전부 이 패턴 — '건축물 연차별 현황' 2020 한 키에 구간값 6개).
- 참고: 자동병합 경로(`agents/image_agent.py` regional_conditions 분기)는
  이미 `항목` 우선으로 조립한다 — 두 경로의 비대칭이기도 하다.

## 목표

02 시트 라벨 병합 후보의 컬럼 배치를 가이드라인 §5.3 의미대로 교정해,
다시리즈 차트의 시리즈별 행이 각자의 키로 병합 심사를 받게 한다.

## 절대 제약

1. **가이드라인 표준 코드·구조 이외의 것을 발명하지 않는다.** 시리즈 라벨은
   관찰값 `항목`에 이미 있는 원문 유래 텍스트만 쓴다(합성·요약 금지).
2. G1~G5 게이트 판정 로직·V3 중복 방지·estimated 관례·기본 False 불변.
3. **프롬프트 수정 금지** — 캐시 전량 히트(재호출 0)가 인수 조건.
   서울(`.cache/llm_responses_gemini_v5`)과 재추출된 강원·경기 캐시로 실측한다.
4. 적용 범위는 `regional_conditions` 라벨 병합 후보 조립만. 자동병합 경로,
   타 시트 분기, 채점기(`scripts/`)는 이번 라운드에서 수정 금지.
5. 코드·주석·커밋 한국어, push 금지, 커밋별 `python -m pytest tests/ -q` 통과.

## 구현

### S1 `_visual_candidate_row`의 regional_conditions 분기 교정 (organizer_agent.py)

현행:
```python
"지표세부범주": _visual_explicit_value(observation, fields, "지표세부범주") or "",
"지표명": _visual_explicit_value(observation, fields, "지표명") or item,
```

교정(가이드라인 §5.3 의미 배치):
1. `시리즈라벨 = 항목` (관찰값/fields의 "항목"), `차트지표명 = fields의 "지표명"`.
2. `지표명`:
   - 시리즈라벨이 있고, `dedup_key_text` 기준 차트지표명과 다르면 → **시리즈라벨**
     (guideline indicator_name = 개별 지표. 예: "0-14세 인구", "10년 미만").
   - 시리즈라벨이 없거나 차트지표명과 같으면 → 현행 폴백 유지(차트지표명 or item).
3. `지표세부범주`(guideline indicator_subcategory = 중분류):
   - vision이 지표세부범주를 명시했으면 그 값(현행 유지).
   - 없으면, 2에서 지표명으로 시리즈라벨을 쓴 경우에 한해 **차트지표명**을 배치
     (예: "연령별 인구", "건축물 연차별 현황"). 그 외는 현행 공란 유지.
4. 병합 키는 기존 그대로(`지자체명+지표범주+지표명+연도`) — 지표명이 시리즈별로
   갈라지므로 키 붕괴가 자연 해소된다. `_VISUAL_MERGE_KEY_FIELDS` 수정 금지.

### S2 테스트

1. 다시리즈: 같은 fields.지표명("건축물 연차별 현황") + 항목이 다른 관찰값
   2건이 flag-on에서 **둘 다 병합**되고(키 상이), V3 경고 0.
2. 배치 검증: 병합 행의 지표명="10년 미만", 지표세부범주="건축물 연차별 현황".
3. 단일 시리즈(항목=차트지표명 또는 항목 없음): 기존 조립과 동일(회귀 방지).
4. flag-off: 산출 불변(라벨 병합 경로 밖 무접촉) — 기존 스냅샷 테스트로 확인.

## §5 실측 절차와 합격 게이트 (구현 인수 후 Claude 독립 재실행, 비용 0)

주의: 캐시 재실행은 **.venv 파이썬 필수**(M2-4.2 실측 문서의 환경 절 참조).

1. **flag-off 서울**: 골든 지표 무변(이 수정은 라벨 병합 경로만 지나감).
2. **flag-on 서울**: M2-4.2 실측(병합 108·경고 36) 대비 —
   - V3 시각-시각 경고 36 → **0~한 자릿수** (시리즈 붕괴 해소의 직접 증거),
   - 병합 행 수 증가분과 그 내역 보고,
   - 텍스트 유래 리콜·값일치율 무하락, 시각 유래 리콜 변화 **보고**
     (이번 라운드는 목표 수치를 강제하지 않는다 — 1차 효과는 납품물의 병합
     손실 회복이고, 채점 리콜은 명명 발산이 남아 부분 회복으로 예상됨을
     명세 단계에서 미리 기록한다).
3. **강원·경기 flag-on**(재추출 캐시): 병합 행 표본 20개 수동 열람 —
   시리즈 라벨이 지표명에, 중분류가 세부범주에 배치됐는지, 오병합·연도
   이상치 없는지. 경고가 병합 대비 과반이면 불합격.
4. 산출물: `docs/audit/M2-4.2_병합경로_실측_20260712.md`에 M2-4.3 절 추가
   또는 별도 실측 문서. 기본 True 전환 판단은 이 실측과 강원·경기 게이트를
   합쳐 사용자 결정.
