## 수정 항목

### S1. 06 감축목표 스케일 정합 — P0 (organizer_agent.py)

**증상(실측)**: 서울 06 값일치율 0.21의 실원인. ① dedup 키
`["지자체명","목표수준","목표범위","부문","목표연도"]`(`_clean_reduction_targets`,
organizer_agent.py:864)에 **기준연도가 없어** 기준연도 2005 행과 2018 행이
한 키로 병합되고, ② 값 채움 병합이 출처 페이지가 다른(=단위 스케일이 다른)
행들의 값을 한 행에 섞는다 — 실물: 기준배출량 49,445(천톤)·목표감축량
9,802,000(톤)·목표배출량 29,667(천톤)이 한 행. 06 헤더에는 단위 칼럼이
없어(가이드라인 §5.2 계약) 시트 안에서 식별 불가.

**지자체 불변 근거**: 가이드라인 §2.6.1이 기준연도(base_year)를 목표 식별
필드로 규정, §7 체크리스트가 "천톤과 톤 변환에서 1,000배 오류"를 보편 검증
항목으로 명시. 특정 문서 표기와 무관한 스키마·산술 사안.

**수정**:

- **S1a**: 06 dedup 키에 `기준연도`를 편입한다 —
  `["지자체명","목표수준","목표범위","부문","기준연도","목표연도"]`.
  `_BLANK_ABSORB_FIELDS_BY_KEY`에 reduction_targets 키 항목을 추가해
  **기준연도 공란 행**은 기존 흡수 규칙(타 키 필드 전부 일치 + 수치 충돌
  없음 → 흡수, 충돌 시 conflict 기록)으로 처리한다.
- **S1b**: 06 dedup의 값 채움/충돌 판정에 **1000배 스케일 가드**를 넣는다.
  같은 키의 두 행을 병합할 때, 공통으로 채워진 수치필드(기준배출량·배출전망·
  목표감축량·목표배출량 중)가 있고 그 값이 1000배 정확비(비율이 1000의
  ±0.5% 이내, 방향 무관)이면 **같은 사실의 톤↔천톤 표기 차**로 판정: 값을
  덮지도 채우지도 않고 first-wins 유지 + 검증리포트에
  `스케일 표기 차 의심(톤↔천톤)` 경고를 남긴다. 공통 필드가 없으면 양 행의
  배출량류 필드 최대 절대값(스케일 서명)을 비교해 비율 ≥1000이면 **교차
  채움을 금지**하고(각 행이 이미 가진 값은 유지) 같은 경고를 남긴다.
  자동 환산(값 변경)은 하지 않는다 — 기존 "스케일 혼재는 리포트만"
  관례(organizer_agent.py:1820)의 연장.

**수용**: 기준연도 상이 행이 병합되지 않는 테스트 / 기준연도 공란 행 흡수·
충돌 테스트 / 1000배 정확비 공통 필드에서 채움·덮음이 일어나지 않고 경고가
남는 테스트 / 1000배가 아닌 정상 충돌은 기존 conflict 경로 불변 테스트.

### S2. 채점기 06 스케일 동치 병기 — P0 (scripts/golden_score_*)

**증상(실측)**: 06 값 비교가 순수 수치 0.5% 상대오차뿐이라
(`_상대오차일치`, golden_score_matching.py:246-254), 출력이 원문 그대로
톤(52,342,000)이고 골든이 천톤(52,342)이면 전부 값불일치가 된다. 06은
값필드에 단위조차 없어(golden_score_contract.py:38) 구분 불가.

**지자체 불변 근거**: 채점기 사안(파이프라인 무관). 톤↔천톤 병기는
가이드라인 §2.6.1이 명시한 원문 표기 자유("OO톤CO2eq 또는 OO천톤CO2eq").

**수정**: 06_감축목표의 수치 값필드 중 **기준배출량·배출전망·목표감축량·
목표배출량**(감축률(%) 제외)에 한해, 기존 판정 불일치일 때 두 값의 비율이
10^3 또는 10^6의 ±0.5% 이내이면 `스케일동치`로 별도 집계한다.

- 헤드라인 `값일치율` 정의·수치는 **바이트 불변**. 요약에
  `값일치율(스케일동치 포함)` 칼럼과 스케일동치 쌍 수를 병기하고, 리포트에
  스케일동치 쌍 목록 절(시트·키·골든값·출력값·배율)을 추가한다 — 의미완화
  38쌍 목록과 같은 형식.
- 시트 06 외에는 적용하지 않는다(03·04·05는 단위 필드가 값비교에 있어
  스케일 차가 단위 불일치로 이미 드러난다).

**수용**: 52,342,000 vs 52,342 → 스케일동치 집계·값일치율 불변 테스트 /
1000배가 아닌 불일치는 기존대로 값불일치 테스트 / 기존 채점 산출(값일치율·
리콜·의미완화·문자유사) 바이트 불변 테스트(기존 픽스처 재사용).

### S7. IPCC 부문 정규식의 연도 오탐 차단 — P2 (organizer_agent.py)

**증상(코드 검토, v5.3 잔여 L1)**: `_IPCC_SECTOR_PREFIX_RE =
^\s*(?P<code>[1-4][A-D]?\d*)\s*(?P<label>...)`(organizer_agent.py:108)에서
[A-D]가 선택이라 "2018 에너지"의 "2018"이 code로 매칭될 수 있다(실데이터

로 제한한다: `(?P<code>[1-4](?:[A-D]\d*)?)`. "1A", "3C7", "1"은 매칭,
"2018"은 비매칭.

**수용**: "1A 연료연소"·"3C7 벼재배"·"1 에너지" 기존 매핑 유지 테스트 +
"2018 에너지" 비매칭(부문 원문 유지) 테스트.

### S8. 03 라벨 병합 연도 상한의 문서 기준화 — P1 (organizer_agent.py, config.py)

**증상(실측)**: S2(M2-4.2)가 03 연도 범위를 1990~2050으로 넓힌 결과
(`IMAGE_CHART_MERGE_YEARS_BY_SHEET`, config.py:512-515) 전망성 행이 현황
시트(03)에 들어올 수 있다 — 강원 03의 2033·2040 흡수 전망 행은 M2-4.5
