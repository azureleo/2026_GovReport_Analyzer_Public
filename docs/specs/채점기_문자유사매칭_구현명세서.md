## 근거 실측 (2026-07-13, 서울 v45 산출물 기준 — 명세 첨부 데이터)

미매칭 시각 골든 245행(02, 의미완화 매칭 28행 제외)의 사망 분포를 전수 분석:

- **~219행: 명명 밖** — 값일치 출력행 자체가 없거나(61), 우연 값일치뿐(158).
  판독유실·차단 잔존 몫(다음 프롬프트 라운드 ①의 대상).
- **17행: 전제(값 0.5%+연도+단위) 통과, 토큰 자카드 <0.6** — 전수 사람 확인
  결과 **전부 진짜 쌍**. 원인은 어휘가 아니라 **토큰화**:
  - 붙여쓰기: 골든 '자동차 등록 대수(휘발유)' vs 출력 '휘발유 차량'+세부범주
    '연료별 자동차 등록대수' — '등록대수'가 {등록, 대수}와 토큰 불일치.
  - 합성명 구조차: 골든 '공원 수(어린이공원)' vs 출력 '어린이공원'.
- 기타: 골든 간 교차 동률 1행, 연도 실측 차이 1행(에너지다소비건물 2020 vs
  2021 — 원문 확인 대상, 채점기 사안 아님).

**문자 2-gram 자카드 캘리브레이션** (지표명+지표세부범주 연결, 비단어문자
제거): 17쌍 = 0.21~0.64(0.30 이상 14쌍) vs 무작위 3,000쌍 = 95백분위 0.06,
최고 0.41. 우연쌍은 전제를 거의 통과하지 못하므로(같은 연도·단위에서 값
0.5% 일치가 선결) 실질 위험은 전제 통과 오결합뿐이다.

기각한 대안(같은 실측 근거): 토큰 자카드 임계 0.6→0.5 완화(수확 4행,
문자유사와 중복), 동의어 사전(재료 부족·발명 위험), 03/05/06 확장(미매칭이
전부 판독유실이라 수확 0 — ① 라운드 후 재검토), 파이프라인 명명 변경
(산출물 지표명은 원문 유래 그대로가 원칙 — 골든의 합성명을 채점기가 흡수).

## 구현

### S1 문자유사 후보 (`scripts/golden_score_matching.py`)

1. 텍스트 구성: `지표명 + 지표세부범주`를 이어붙이고 `re.sub(r"[^\w]", "", ...)`
   로 비단어문자 제거(공백·괄호·하이픈 소거 → 붙여쓰기 변형 흡수).
   `dedup_key_text` 수준의 정규화가 필요하면 문자열 전체에 1회 적용.
2. 유사도: 문자 2-gram 집합의 자카드. 길이 1 이하 문자열은 문자열 자체를
   단일 그램으로(빈 문자열은 후보 제외).
3. 전제: 기존 `_의미완화후보`와 동일 — 연도 일치 필수, 단위 상충 시 제외,
   값 상대오차 0.5% 일치 필수. 코드 재사용(전제 검사 함수 분리 권장).
4. 임계: `CHAR_SIMILARITY_MIN_JACCARD = 0.30` (`golden_score_contract.py`에
   상수). 0.20~0.30 구간 후보는 **비매칭**하되 리포트의 후보 목록 절에
   "문자유사 관찰(비매칭)"으로 기록(다음 라운드 재료).
5. 매칭 규칙: 의미완화와 동일 — 골든별 최고 유일, 출력행 선점 배제,
   동률(골든 간·후보 간) 전부 비매칭. 3차(의미완화)가 소비한 골든·출력은
   후보에서 제외(누적 잔여에만 적용).

### S2 리포팅 (`golden_score_matching.py`·`golden_score_report.py`)

의미완화와 동일 패턴의 병기 원칙:
1. 기존 헤드라인 지표(리콜·값일치율·완화매칭수·의미완화매칭수)는
   **바이트 불변** — 문자유사는 어떤 기존 숫자에도 섞지 않는다.
2. 새 키 `문자유사매칭수`, `문자유사매칭쌍`(골든·출력 값, 유사도 포함) 추가.
3. 출처유형별 표에 "시각 유래(문자유사 포함)" 누적 행 추가 — 의미완화 포함
   값에 문자유사 매칭을 더한 누적(의미완화포함출처직렬화와 같은 방식).
4. 값일치율에는 반영하지 않는다(값 일치가 전제라 무의미 — 의미완화와 동일).
5. 리포트(md)에 문자유사 매칭 쌍 전체 목록 절 + 0.20~0.30 관찰 목록 절.

### S3 테스트 (`tests/`)

1. 붙여쓰기 흡수: '자동차 등록 대수(휘발유)' vs '휘발유 차량'/'연료별 자동차
   등록대수' 형 쌍이 전제 충족 시 매칭(≥0.30 확인).
2. 전제 미충족(값 불일치·연도 불일치·단위 상충) 시 유사도 무관 비매칭.
3. 동률 비매칭: 같은 골든에 동일 유사도 출력 2개 → 비매칭.
4. 헤드라인 불변: 문자유사 쌍이 있어도 리콜·값일치율·의미완화매칭수 불변.
5. 3차 소비분 제외: 의미완화로 매칭된 행이 문자유사 후보에 재등장하지 않음.
