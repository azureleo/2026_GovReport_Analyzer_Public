## V1. S3 완화 가드의 값불일치 조건 강화 — P0 (scripts/golden_score_matching.py)

**실측 결함**: 현행 `_세부부문완화후보허용`(양쪽 세부부문 채움·상이 →
무조건 제외)이 **값이 완전 동일한 표기 발산 정당 매칭 ~25건을 제거**해
텍스트 유래 리콜 -1.24pp 회귀를 만들었다. 실례: 04 '폐기물' vs '폐기물
전체'(4,710=4,710), 'LULUCF' vs 'LULUCF 전체'(-151=-151), '간접배출 계' vs
'총배출량'(25,399=25,399), 03 '연료 공급량 기준' vs '총배출량(연료 공급량
기준)'(24,166=24,166). 반면 값 상이 오결합 ~23건('상업' vs '상업/공공'
14,145 vs 3,453 등)의 제거는 정당했다(값일치율 +0.15pp).

**수정**: 완화 티어에서 03·04 후보 제외 조건을 다음 3조건 동시 충족으로
강화한다:

1. 골든·출력 양쪽 세부부문이 모두 채워져 있고,
2. `dedup_key_text` 정규화 후 상이하며,
3. **비교값(배출량)이 불일치** — 양쪽 배출량이 모두 존재하고
   `_상대오차일치`(0.5%)를 만족하면 **매칭 허용**(같은 사실의 표기 발산으로
   간주). 어느 한쪽 배출량이 비어 있으면 **제외 유지**(값 검증 불가 매칭은
   보수적으로 배제).

즉 "세부부문 상이 + 값 일치 → 허용, 세부부문 상이 + (값 불일치 또는 값
검증 불가) → 제외". 한쪽 세부부문 공란 허용 등 나머지 동작은 불변.

**수용 테스트**: 세부부문 상이·값 동일 → 완화 매칭 유지 / 세부부문
상이·값 상이 → 제외(기존 테스트 유지) / 세부부문 상이·한쪽 값 공란 →
제외 / 한쪽 세부부문 공란 → 기존 매칭 유지(기존 테스트). 기존 S3 테스트
중 "값 동일인데 제외" 단언이 있으면 이 지시로 의도 변경됐음을 커밋
메시지에 명시하고 갱신.

**기대 실측(검증자 확인용)**: base 산출물 재채점 시 완화 매칭 회복분은
값 동일 계열(~25건)에 한하고, 값 상이 오결합(~23건)은 계속 제외.
텍스트 유래(의미완화) 리콜 0.6049 → 0.61대 회복, 값일치율 0.8759 무하락.

## V2. 가스종 차단의 자동병합 경로 확장 — P1 (agents/image_agent.py)

**실측 결함**: 경기 03 부문='총 메탄 배출량' 행(visual_only, 2018,
4,271.8)이 잔존. `_gas_sector_key`는 정확히 작동하나 이 행은 image_agent의
**표-고신뢰 자동병합 경로**로 유입되어 organizer 라벨 게이트가 보지 못한다.

**수정**: image_agent의 자동병합 반영 분기에서 대상 시트가
`emissions_regional`·`emissions_management`인 후보에 한해, 부문(관리부문)
값이 organizer와 동일한 판정(`_gas_sector_key` 결과가 `_IPCC_GAS_NAMES`
전체일치)이면 자동 반영을 하지 않고 관찰값(16시트)으로만 남긴다. 판정
함수는 organizer의 `_gas_sector_key`·`_IPCC_GAS_NAMES`를 **임포트 재사용**
(중복 구현 금지 — 정의 이동이 필요하면 utils로 옮기되 기존 임포트 경로
유지). 프롬프트·라우팅·신뢰도 판정은 불변(캐시 키 보존).

**수용 테스트**: 부문 '총 메탄 배출량' 자동병합 후보가 반영되지 않고
관찰값으로 남는 테스트 / 부문 '에너지' 자동병합은 기존대로 반영되는 테스트.

**기대 실측**: 경기 03 '총 메탄 배출량' 행 소멸(경기 병합 -1 또는 03 행
-1), 그 외 3지자체 분포 변화 없음.
