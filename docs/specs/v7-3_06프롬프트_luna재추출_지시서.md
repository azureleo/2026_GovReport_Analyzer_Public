## 2. 작업 항목

### P1 — 06 추출 프롬프트 개정 (`agents/extractor_agent.py`)

- 목표수준 enum을 `총괄|부문|세부부문|세부사업|연차경로`로 확장하고
  "주의"에 판정 지침을 추가한다:
  - 개별 사업·과제 카드(관리번호·성과지표·추진계획 문맥)의 감축 목표는
    `세부사업`. 부문 전체 목표 표(기준배출량·전망·목표배출량 구조)만
    `부문`.
  - 연도가 연속 나열된 연차별 감축량·감축률 경로표의 각 연도 행은
    `연차경로`(그 연도 시점의 목표가 아님). 5년 단위 이정표 목표 표는
    해당 없음.
  - 목표수준은 항상 기입하고, 목표범위(관리권한/지역전체)는 원문 근거가
    불확실하면 생략한다(추측 금지).
- JSON 스키마에 `"사업명힌트": "세부사업일 때 해당 사업명, 그 외 생략"`
  필드를 추가한다.

### P2 — organizer 사업명힌트 처리 (`agents/organizer_agent.py`)

- `_clean_reduction_targets`에서 `사업명힌트`를 내부 필드
  `_사업명힌트`로 이관(엑셀 미출력 — 언더스코어 관례).
- 06 dedup 키: 목표수준이 `세부사업`인 행에 한해 `_사업명힌트`
  정규화값을 키에 편입(빈 값이면 현행 키 그대로) — 서로 다른 카드의
  목표가 병합되지 않게 한다. `_REDUCTION_TARGET_KEY_FIELDS` 자체는
  불변으로 두고 키 생성 지점에서 조건 편입한다.
- S1 재태깅으로 `세부사업`이 된 행은 힌트가 없으므로 현행 동작 유지.

### P3 — vision 프롬프트 fields 공급 강화 (`agents/image_agent.py`)

- fields 지침(현행 "확신할 때만, 추측 금지" 유지)에 한 줄 보강:
  차트 제목·축 라벨·범례·캡션에 분류 근거가 **명시**돼 있으면 해당
  필수 분류 필드를 생략하지 말고 반드시 fields에 포함하라. (근거 없는
  기입 금지는 그대로 — 환각 방지 문구를 약화시키지 말 것.)
