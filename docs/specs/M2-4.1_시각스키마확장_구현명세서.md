# M2-4.1 시각 판독 스키마 확장 구현명세서

> 대상 브랜치: `feat/v6-measurement-baseline` (HEAD 9c3cbbd 이후). 새 브랜치

## 측정 근거 (전부 실측)

1. M2-4 게이트 재실측(`docs/audit/M2-4_활성화게이트_실측_20260710.md`): 3지자체
   병합 0 — G1·G2 통과 후보의 유일 병목이 분류 키 부재(서울 G3 단독 차단:
   02 지표범주 76건, 03 배출유형 26건). vision 프롬프트(`agents/image_agent.py`
   `CHART_TABLE_SYSTEM`·`_chart_to_table`)가 이 필드들을 묻지 않는다.
2. luna 표본채점(`docs/audit/서울시각요소_luna_표본채점_상세_20260710.md`):
   표 인쇄형 17/17, 환각 0. 최대 오류 = 감축목표 차트(그림 5-5형)에서
   감축량↔목표배출량 역할 스왑 8건 — 값은 원문 그대로, 역할 배정만 오류.
   → 스키마가 "값의 역할"을 명시적으로 물으면 완화될 개연성.
3. 캐시 키(`utils/llm_cache.py` `_request_key`)는 system·prompt·image 해시 포함
   → 프롬프트 변경 시 vision 항목만 자연 미스, 텍스트 캐시 히트는 보존.
   **캐시 디렉터리 변경 금지.**

## 목표

vision 판독의 행별 `fields`에 **대상 시트의 1차 키 필드와 값 역할**을 담게 해,
M2-4 병합 게이트(G1~G5)가 실데이터에서 발화 가능해지도록 한다.

이번 라운드는 M2-4와 달리 "기본 실행 출력 바이트 불변"이 아니다 — vision 응답이
바뀌므로 16 시트·자동병합 결과가 달라질 수 있다. 대신 **측정 게이트**로 통제한다:
재추출 후 골든 채점 리콜·값일치율 무하락 + 인벤토리 감사 리콜 무하락(§실측 절차).

## 절대 제약

1. **지자체 불변**: 프롬프트에 추가하는 분류값은 가이드라인 표준코드만 —
   지표범주 {인문사회, 자연환경, 경제산업, 에너지}, 배출유형 {직접배출, 간접배출,
   흡수원}, 직간접구분 {직접, 간접}. 특정 지자체·특정 문서의 문구/그림 번호를
   프롬프트에 넣지 않는다(차트 유형의 일반 규칙 서술은 허용).
2. **모르면 생략**: 키 필드를 확신 못 하면 추측하지 말고 fields에서 생략하라고
   프롬프트에 명시(G3가 걸러낸다). `estimated`는 지금처럼 **추정일 때만 true** —
   이 관례를 바꾸지 않는다(organizer G1이 이 관례에 정합).
3. **organizer 게이트(G1~G5) 판정 로직 불변**. 허용되는 organizer 변경은 단 하나:
   `_visual_candidate_row`의 reduction_targets 분기에서 `값역할` 필드를 읽어 값을
   올바른 컬럼에 배치(§2.3). 그 외 organizer 수정 금지.
4. `VISUAL_MERGE_LABELED_ENABLED` 기본 False 불변. 기존 자동병합 경로의 판정
   조건(`_chart_merge_decision`) 불변 — fields에 키가 늘어나는 것은 허용, 판정
   규칙 변경은 금지.
5. LLM_CACHE_DIR 관련 코드·기본값 불변. 코드·주석·커밋 한국어, push 금지,
   커밋별 `python -m pytest tests/ -q` 통과.

## 구현

### 2.1 CHART_TABLE_SYSTEM (image_agent.py) — 시트별 fields 예시 확장

기존 예시(vehicle/energy/ghg/strategy)를 유지하되, 다음을 추가한다:
- 규칙 추가: "각 행의 fields에는 아래 시트별 **필수 분류 필드**를 이미지·캡션·
  주변 라벨에서 읽을 수 있을 때만 넣으세요. 확신이 없으면 그 필드를 생략하세요
  (추측 금지)."
- 시트별 필수 분류 필드(fields 예시로 제시):
  - 지역여건 통계(차량·에너지·인구 등): `{"지표범주": "인문사회|자연환경|경제산업|에너지", "지표명": "...", "연도": 2022}`
  - 배출현황: `{"배출유형": "직접배출|간접배출|흡수원", "부문": "건물", "세부부문": "(보이면)", "연도": 2021}`
  - 관리권한 배출: `{"관리부문": "건물", "직간접구분": "직접|간접", "연도": 2021}`
  - 배출전망: `{"시나리오": "BAU", "부문": "건물", "연도": 2030}`
  - 감축목표: `{"값역할": "목표배출량|목표감축량|기준배출량|배출전망", "목표수준": "총괄|부문", "목표범위": "지역전체|관리권한", "부문": "건물", "목표연도": 2030}`
  - 재정계획: `{"계획구분": "...", "사업명": "...", "재원구분": "...", "연도": 2030}`
- 역할 스왑 방어 규칙 추가(일반 서술): "감축목표 차트에서 막대·수치가 '감축량'인지
  '목표배출량'인지 축·화살표·범례로 구분해 값역할에 명시하세요. 구분이 안 되면
  값역할을 생략하세요."

### 2.2 _chart_to_table / _chart_to_table_batch 프롬프트

두 호출부의 JSON 예시 `"fields": {{"시트별 추가 필드": "값"}}`를 §2.1과 정합하게
갱신(간결 요약형이어도 됨 — 상세 규칙은 system에 있음). 두 프롬프트 외 다른
프롬프트(텍스트 추출·triage·fallback)는 문면 불변.

### 2.3 organizer: reduction_targets 값역할 배치 (유일한 organizer 변경)

`_visual_candidate_row`의 reduction_targets 분기: `값역할`이 fields에 있으면
값을 해당 컬럼(목표배출량/목표감축량/기준배출량/배출전망)에 배치하고, 나머지
값 컬럼은 fields 명시값만 사용. `값역할` 부재 시 현행(목표배출량) 유지.
G5 비교값 필드는 기존 `_VISUAL_MERGE_VALUE_FIELDS`(목표배출량) 유지 — 값역할이
목표배출량이 아닌 행은 목표배출량이 비므로 G3 "비교값 누락"으로 차단된다(보수).
이 차단 사유가 값역할별로 구분되도록 차단 메시지에 값역할을 덧붙여도 좋다.

## 테스트 (신규)

1. CHART_TABLE_SYSTEM·두 프롬프트에 필수 분류 필드 지시가 포함되는지(문자열 검사:
   "지표범주", "배출유형", "값역할", "추측 금지" 등 핵심 토큰).
2. `estimated` true-only 관례 문구가 유지되는지(기존 규칙 7 문면 불변 검사).
3. 값역할 배치 단위 테스트: 값역할=목표감축량인 관찰값 → 목표감축량 컬럼 배치
   + 게이트에서 비교값 누락 차단(현행 보수 동작), 값역할=목표배출량 → 병합 경로.
4. 기존 전체 테스트(212) 통과 — 프롬프트 문자열에 의존하는 기존 테스트가 있으면
   신규 문구와 정합하게만 갱신(동작 계약 변경 금지).

## 실측 절차 (구현 인수 후 — Claude/사용자 실행, 구현 범위 밖)

1. 서울 재추출 1회: 에이전트 모드(vision=gpt-5.6-luna, quota) 권장 또는 API
   (vision=pro, $1~5). 같은 캐시 디렉터리(텍스트 히트, vision 신규).
2. flag-off 채점: 골든 리콜·값일치율, 인벤토리 감사 리콜 — 기존 기준선 대비
   무하락 확인(자동병합 경로 회귀 감시).
3. flag-on 재정제(캐시 재실행, 비용 ~0): 병합/생략/경고/차단 분포 + 골든 채점.
   기대: 병합 > 0, G5 생략·경고 실례 ≥ 1, 리콜·값일치 무하락.
4. E083/E084(그림 5-5/5-6) 값역할 재채점 — 역할 스왑 8건 개선 여부.
5. 강원·경기 반복(분포 상식성). 결과는 실측 보고서에 절 추가.
