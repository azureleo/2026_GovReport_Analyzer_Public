# LLM 기반 지자체 탄소중립 계획 정보 추출 시스템

## 1. 프로젝트 개요

### 배경

지자체별 탄소중립 기본계획은 수백 페이지에 달하는 PDF 문서로 제출됩니다. 이 문서에서 온실가스 배출량, 감축 목표, 에너지 소비 현황, 감축 전략 등의 정형 데이터를 수작업으로 추출하는 데는 많은 시간이 소요됩니다.

본 시스템은 **Google Gemini LLM** 을 활용하여 PDF 문서를 자동으로 분석하고, 환경부 표준 양식에 맞는 Excel 파일을 자동 생성합니다.

### 핵심 기능

- PDF 텍스트·표·이미지 동시 분석
- 환경부 가이드라인 기반 5개 시트 자동 생성
- 배치 처리 방식으로 500페이지 이상 대용량 PDF 처리 가능
- 중복 제거, 단위 정규화, 이상치 탐지 등 자동 데이터 정제
- 품질 점수 기반 자동 재시도

## 2. 시스템 아키텍처

본 시스템은 **5개의 전문 에이전트** 가 파이프라인으로 연결된 멀티 에이전트 구조입니다.

```
입력 PDF
    │
    ▼
┌─────────────────────────────────────────────────┐
│              에이전트 5: 감독관 (Supervisor)          │
│  전체 파이프라인 조율 · 품질 점수 계산 · 자동 재시도     │
└──────────────────┬──────────────────────────────┘
                   │
    ┌──────────────┼──────────────────────────┐
    ▼              ▼                          ▼
┌───────┐   ┌───────────┐              ┌──────────┐
│에이전트1│   │ 에이전트 2  │              │에이전트 2b│
│가이드라인│   │텍스트·표 추출│              │이미지 분석│
└───────┘   └─────┬─────┘              └────┬─────┘
                  │                         │
                  └──────────┬──────────────┘
                             ▼
                    ┌────────────────┐
                    │   에이전트 3    │
                    │  정리·정제     │
                    └───────┬────────┘
                            ▼
                    ┌────────────────┐
                    │   에이전트 4    │
                    │  엑셀 작성     │
                    └───────┬────────┘
                            ▼
                       출력 Excel
```

### 에이전트별 역할

| 에이전트 | 파일 | 역할 |
|---|---|---|
| **에이전트 1** 가이드라인 | `agents/guideline_agent.py` | 환경부 HWP 가이드라인 파싱 또는 내장 스키마 로드. 추출 대상 5개 시트 정의 |
| **에이전트 2** 텍스트 추출 | `agents/extractor_agent.py` | PDF 텍스트·표를 10페이지 단위 배치로 처리. 시트별 분리 API 호출로 JSON 추출 |
| **에이전트 2b** 이미지 분석 | `agents/image_agent.py` | PDF 내 그래프·표 이미지를 Vision API로 분석하여 추가 데이터 보완 |
| **에이전트 3** 정리·정제 | `agents/organizer_agent.py` | 중복 제거, 부문명 정규화, 이상치 탐지, 단위 검증 등 데이터 정제 |
| **에이전트 4** 엑셀 작성 | `agents/excel_agent.py` | 정제된 데이터를 5개 시트 Excel 파일로 저장 |
| **에이전트 5** 감독관 | `agents/supervisor.py` | 전체 파이프라인 조율, 품질 점수 계산(0~100), 기준 미달 시 자동 재시도 |

## 4. 설치 방법

### 사전 요구사항

- **Python 3.10 이상**
- **Google Gemini API 키** ([Google AI Studio](https://aistudio.google.com/)에서 무료 발급 가능)

## 5. 사용 방법

### 기본 실행

```bash
py main.py "서울특별시_탄소중립계획.pdf"
```

실행 시 자동으로 `탄소중립_추출결과_YYYYMMDD_HHMMSS.xlsx` 파일이 생성됩니다.

### 출력 파일명 지정

```bash
py main.py "서울특별시_탄소중립계획.pdf" --output "서울_결과.xlsx"
```

### 전체 옵션

```
사용법: py main.py <pdf_path> [옵션]

필수 인수:
  pdf_path              입력 PDF 파일 경로

선택 옵션:
  -o, --output PATH     출력 Excel 파일 경로
  -g, --guideline PATH  환경부 가이드라인 HWP 파일 경로 (없으면 내장 스키마 사용)
  -k, --api-key KEY     Gemini API 키 (없으면 .env 파일에서 로드)
  -r, --retries N       품질 미달 시 재시도 횟수 (기본값: 2)
  -v, --verbose         상세 로그 출력
  --no-images           이미지 분석 건너뜀 (처리 속도 향상)
```

### 실행 예시

```bash
# 기본 실행
py main.py "서울특별시_탄소중립계획.pdf"

# 출력 경로 지정
py main.py "경기도_수원시_탄소중립계획.pdf" -o "수원_결과.xlsx"

# 이미지 분석 제외 (빠른 실행)
py main.py "서울특별시_탄소중립계획.pdf" --no-images

# 상세 로그 출력
py main.py "서울특별시_탄소중립계획.pdf" -v
```

### 실행 소요 시간

515페이지 PDF 기준 (서울특별시 탄소중립 기본계획):

| 단계 | 소요 시간 |
|---|---|
| PDF 파싱 | 약 40초 |
| 텍스트 추출 (52배치) | 약 60~90분 |
| 이미지 분석 (50개) | 약 15~20분 |
| 정리·정제 | 수초 |
| 엑셀 작성 | 수초 |
| **총 소요** | **약 90~120분** |

> `--no-images` 옵션 사용 시 약 20~30분 단축됩니다.

## 6. 출력 파일 형식

생성되는 Excel 파일은 다음 **5개 시트** 로 구성됩니다.

### 시트 1: 용도별 자동차(현황)

지자체의 용도별·차종별 자동차 등록 현황

| 컬럼 | 설명 |
|---|---|
| 지자체명 | 해당 지자체 이름 |
| 용도 | 승용 / 화물 / 버스 / 이륜 / 특수 / 승합 |
| 차종 | 경유 / 휘발유 / LPG / 전기 / 수소 / 하이브리드 등 |
| 대수(대) | 등록 차량 수 |
| 1일 평균 주행거리(km/대) | 차량 1대당 하루 평균 주행 거리 |

### 시트 2: 용도별 에너지(현황)

용도별 에너지원 소비량 현황

| 컬럼 | 설명 |
|---|---|
| 지자체명 | 해당 지자체 이름 |
| 용도 | 가정 / 상업 / 공공 / 산업 / 수송 등 |
| 석유(에너지유) / 석유(LPG) / 석유(비에너지유) | 석유계 에너지 소비량 |
| 가스 / 전력 / 열 / 신재생 | 기타 에너지원 소비량 |

### 시트 3: 온실가스(현황전망목표)

연도별 부문별 온실가스 배출량 (현황·전망·목표)

| 컬럼 | 설명 |
|---|---|
| 지자체명 | 해당 지자체 이름 |
| 배출유형 | 직접배출 / 간접배출 / 흡수원 |
| 종류 | 현황 / 전망(BAU) / 목표(NDC) |
| 부문 | 건물 / 수송 / 농축산 / 폐기물 / 흡수원 / 전환 / 산업 / 수소 / 합계 |
| 2018 ~ 2034 | 연도별 온실가스 배출량 (tCO2eq) |

### 시트 4: 감축전략(계획실적)

부문별 감축 사업의 계획·실적 데이터

| 컬럼 | 설명 |
|---|---|
| 지자체명 | 해당 지자체 이름 |
| 배출유형 | 직접배출 / 간접배출 |
| 감축전략_부문 | 건물 / 수송 / 폐기물 / 전환 / 흡수원 등 |
| 감축사업명 | 감축 사업의 상위 이름 |
| 감축사업명_세부 | 세부 사업명 |
| 구분 | 공통 / 특화 |
| 성과지표 | 사업 성과 측정 지표 |
| 종류 | 계획(지표) / 계획(감축량) / 계획(예산) / 실적(지표) / 실적(감축량) / 실적(예산) |
| 2018 ~ 2034 | 연도별 계획·실적 수치 |

### 시트 5: 지자체별 요약카드

탄소중립 계획의 핵심 정보 요약

|---|---|
| 지자체명 | 해당 지자체 이름 |
| 항목 | 배출유형 / 감축목표(2030) / 감축목표(2035) / 핵심전략 / 배출유형-전략 간 연결성 |

## 8. 동작 원리 상세

### STEP 0: PDF 파싱

PyMuPDF(`fitz`)를 사용하여 PDF 전체를 파싱합니다.

- **텍스트**: 각 페이지의 본문 텍스트 추출
- **표**: PDF 내 표 구조를 텍스트 형태로 변환
- **이미지**: 그래프·표가 포함된 페이지를 PNG로 렌더링 (DPI 150)

### STEP 1: 가이드라인 로드

환경부 HWP 가이드라인 파일이 제공된 경우 파싱하고, 없는 경우 `config.py`에 내장된 5개 시트 스키마를 사용합니다.

### STEP 2: 텍스트·표 추출 (에이전트 2)

**배치 처리**: 전체 페이지를 10페이지씩 나누어 처리합니다. 515페이지 PDF → 52개 배치.

**키워드 프리필터**: 각 배치에서 시트별 키워드가 없으면 해당 시트의 API 호출을 건너뜁니다. 불필요한 API 비용을 절감합니다.

```
배치 1 텍스트 → [온실가스 키워드 있음?] → YES → GHG 추출 API 호출
               → [자동차 키워드 있음?] → NO  → 건너뜀
               → [에너지 키워드 있음?] → NO  → 건너뜀
               ...
```

**시트별 분리 호출**: 5개 시트를 한 번의 API 호출로 처리하지 않고, 시트별로 별도 호출합니다. 출력 토큰 한계(65,536)로 인한 JSON 잘림 현상을 방지합니다.

**JSON 강제 출력**: `response_mime_type="application/json"` 설정으로 Gemini가 반드시 유효한 JSON을 반환하도록 강제합니다.

### STEP 2b: 이미지 분석 (에이전트 2b)

PDF에서 추출된 이미지(그래프, 도표)를 Vision API로 분석하여 텍스트 추출로 놓친 데이터를 보완합니다.

- 최대 50개 이미지 분석 (비용 제어)
- 분석 유형: 표, 그래프, 꺾은선, 기타

### STEP 3: 정리·정제 (에이전트 3)

추출된 원시 데이터를 다음 과정으로 정제합니다.

| 정제 항목 | 설명 |
|---|---|
| **부문명 정규화** | 140+ 이형어를 표준 부문명으로 통일 (IPCC 코드, 복합 표기 등 포함) |
| **중복 제거** | 같은 지자체·배출유형·종류·부문 조합의 행을 병합 |
| **이상치 탐지 1단계** | 절대값 기준: 5억 tCO2eq 초과 값 제거 |
| **이상치 탐지 2단계** | 그룹 내 중앙값 200배 초과 값 제거 (단위 혼재 오류 탐지) |
| **에너지 합산행 제거** | 세분 용도가 있으면 합산 용도 행(가정·상업 등) 자동 제거 |
| **자동차 합산행 제거** | 세분 차종(경유/휘발유/LPG)이 있으면 내연기관 합산행 제거 |
| **주행거리 검증** | 10,000 km/일 초과 비상식적 값 제거 |
| **코드명 중복 제거** | `B1`(코드) + `기존 건물 ZEB 전환`(한글명) 이중 등록 통합 |

### STEP 4: 엑셀 작성 (에이전트 4)

openpyxl을 사용하여 5개 시트 Excel 파일을 생성합니다.

- 헤더 행: 파란 배경 + 흰 글씨
- 연도 컬럼: 연파랑 배경
- 짝수 행: 연회색 배경
- 숫자: `#,##0.00` 형식
- 틀 고정: 주요 기준 컬럼 고정

### 품질 점수 계산

| 항목 | 감점 |
|---|---|
| 지자체명 미확인 | -20점 |
| 온실가스 데이터 없음 | -30점 |
| 온실가스 현황 데이터 없음 | -15점 |
| 온실가스 목표 데이터 없음 | -10점 |
| 연도별 채움률 20% 미만 | -10점 |
| 감축전략 데이터 없음 | -10점 |
| 요약카드 빈 항목 (개당) | -3점 |

점수가 **50점 미만**이면 파이프라인 전체를 재시도합니다 (최대 2회).

## 10. 알려진 한계 및 주의사항

### 데이터 정확도

- LLM 특성상 PDF 내 서로 다른 표의 값이 혼재될 수 있습니다.
- 단위가 명시되지 않은 수치는 tCO2eq로 가정하여 추출됩니다.
- PDF 스캔 품질이 낮거나 비정형 레이아웃인 경우 정확도가 저하될 수 있습니다.

### API 제한

- Gemini 무료 플랜은 분당 호출 수 제한이 있어 처리 속도가 느릴 수 있습니다.
- 503 오류 발생 시 지수적 백오프로 자동 재시도합니다 (최대 3회).

### PDF 형식

- 텍스트 레이어가 없는 이미지 PDF는 이미지 분석 에이전트만 사용되어 정확도가 낮아집니다.
- 한글 PDF에 최적화되어 있습니다.
