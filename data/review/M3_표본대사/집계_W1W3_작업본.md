## 0. 산식(공통) — 재계산 가능 형태

프로브 JSON `시트별.<시트>`에서: `r = 값합의율 = 값합의쌍수/값비교쌍수`, `불일치분 = 1 − r`.

표본(시트당 값불일치 10행)에서 백엔드 X ∈ {A(flash-lite), B(luna)}의 **불일치 중 정답비율**:

```
p_X = (X정답 + 둘다정답 + 축상이) / 판정가능표본수      … 판정불가는 분모에서 제외
추정 값일치율_X = r + (1−r) × p_X                      … 합의쌍 전부 정답(q=1) 가정
밴드 판정: 추정 값일치율_X ≥ r − 4pp 이면 유지
```

판정 코드 → 정오 매핑: `A정답`(A 정 · B 오) / `B정답`(B 정 · A 오) / `둘다정답`·`축상이`(둘 다 원문값) / `둘다정답아님`·`원문없음`(둘 다 오) / `판정불가`(추정 제외).

한계(명시): ① 표본은 **값불일치 행만** 커버 — 값합의쌍의 공통 오류(q<1)는 관측 불가(경기 03 원문없음 9행이 값불일치 축에서 확인된 공통 오류 실물 — 합의쌍 안에도 같은 유형이 있을 수 있다). 따라서 추정치는 상향 편의가 있는 점 추정이며, 밴드의 "하한" 성격 검증은 서울 골든 교차(§2.2)가 보완한다. ② 표본은 각 지자체 값합의율 하위 3시트에 국한 — 시트 외 일반화는 밴드 규칙 자체(4pp 하한)에만 의존.
